# 中国式赌狗 v1.3 内容与实现边界

本文件对应 `src/game/core.js`、`src/game/narrative.js` 和现有 JSON 内容。v1.3 提供可以从出生完整推进至 80 岁的单机人生玩法；下列区别用于说明实际内容和扩展边界。

## 已接入的叙事内容

| 内容 | 当前实现 |
|---|---|
| 12 种家庭 | 权重随机或指定；随机金额、初始属性、家庭介绍进入实际状态。 |
| 12 个人生章节 | 在跨越年龄时注册，按事件队列展示；晚到的主线不会因超过原年龄窗口而失效；服刑延期，60/70/80 岁适配狱中场景，80 岁不为补章阻止结算。 |
| 219 个事件 | 全部通过统一资格、年龄、分类、权重和已发生记录进入调度，没有只接一小部分固定事件。 |
| 659 个选项、966 个结果 | 真实读取数据中的门槛、权重和效果；显示事件时固定本次各选项结果，选择时校验并执行。 |
| 78 条明确预约边 | 记录触发来源、到期回合和截止回合；届时重验资格，不满足则等待，过期留下未完成记录。 |
| 24 个历史原型 | 历史回放按实际日期门槛排队；时代乱流每局抽取 6–10 个、分散发生。 |
| 28 个结局 | 使用真实状态谓词匹配，按优先级排序；55–79 岁可结算后续玩，80 岁收盘。 |

219 是一个内容池，不是一局固定播放的 219 张卡。家庭、年龄、就业、持仓、债务、人际状态、选择及已经读过的事件决定哪些卡可达。并非每个人都必然进入资金盘、结婚、创业或获得天使退出；不满足条件的支线不会凭空补发资产和身份。

12 条编剧剧情弧通过事件池、条件、选择与预约组成。明确编码的后续预约有 78 条，按结果中的预约记录计数，包含不同结果通往同一节点的记录；不表示 78 条独立长线故事，也不把文档中的每一次人物关联算作自动连锁。v1.2 另为阿豪、林夏、老周增加共 15 个分支节点，主线安排初次见面，后续选择影响约定和关系，人物页读取真实已发生的共同经历。

## 市场为主的节奏

成年后安排阶段默认进入投资市场。每回合两次生活安排之外，另有三个压缩交易日、每日六次市场操作；可以直接推进人生而不必用完次数。普通随机故事每两回合最多补入一件；主要章节、危机、法律事件和到期预约优先，历史冲击仍按各自模式推进。童年和服刑保留单独的节奏。

约七成市场体验是设计目标。v1.2 按安排机会和故事数量计算的 73.4% 不适用于新增日内操作后的版本；本版未把操作容量宣称为真实玩家停留时长，仍需试玩校准。

## 市场与钱的实现

游戏有十一类实际可持有和结算的投资产品（含加密现货与日内合约），组合为十个投资界面，另有一个虚构网赌界面，以及独立的经营资产、借款、债权和生活开支。金额保存为安全整数分。每次操作校验金额并原子提交；非法操作返回原因，不会扣了一半款再报错。

首次市场准入检查年龄、自有金融资产、眼力、实际经过的参与时间、模拟次数或相关剧情。界面、订单引擎与剧情投资使用同一组门槛；借款增加现金也增加债务，不能直接买到资格。旧档已有持仓及能从实际记录确认的参与经历迁移保留。现实参考与游戏简化分别写在 [准入说明](V1.2_市场准入与现实参考.md)，不把游戏门槛当成现实统一开户规则。

普通行情使用种子驱动的虚构模型；加密另提供来自 Binance 公共归档的五段真实小时 K 线，共 2,592 根，包含暴涨与暴跌。数据离线打包，游戏不连接账户或实时交易接口；没有真实订单簿撮合、完整波动率曲面、全球税制、全部交易所规则或法律破产程序。真实价格比例用于盈亏，手续费、保证金、强平与收入仍是游戏设计，详见 [行情数据来源](V1.3_行情数据来源.md)。

市场持仓和剧情机会各有明确的资金去向：

- 市场操作生成仓位，后续按价格、费用、到期、保证金、锁定与流动性状态结算。
- 剧情投资只计算本次新投入，按选中结果返还，不再次改写无关旧仓位。
- 剧情锁定投资生成独立权益，估值变化不会发现金。
- 剧情经营成功会把本次返还中的一部分转入实际店铺，不凭空额外赠送等额资产。
- 借款同时增加现金与负债；归零、亏损、结算和续玩不会清除未偿债务。
- 股票、债券、期权、逐仓合约、资金盘、天使股权和房产有不同的退出或失败规则。

新买方期权可选三档行权价和 1/3/5 交易日到期，使用简化内在价值加线性时间价值；旧档期权继续遵守其原回合到期字段；卖方期权允许超保证金赔付。可玩合约采用逐仓保证金模型，不声称已实现全仓交叉抵押。房产引擎具备全款、按揭负债和断供处置规则，属于游戏中的简化融资房产。

## 历史冲击的边界

历史事实摘要与来源存在 `data/history.json`。冲击的数值映射存在 `historyShock()`，是游戏参数，不是历史实际涨跌幅。

冲击根据现有敞口作用于仓位或收入，不对全部现金统一乘倍率。同一回合只执行一个世界冲击，处理记录保存在存档中，阅读事件和读档不会重复扣钱。事件中的新选择发生在冲击之后。

特定事件有专项限制。例如负油价对应 `WTI_2020_05`，Terra 对应 `UST/LUNA`，FTX 对应指定平台敞口，迷因股对应指定个股。通用股票、普通加密现货和普通股指合约不会仅因类别相近就被当作上述资产。没有相应敞口时，这些事件仍可作为新闻和剧情出现；未建模的特定银行存款处置只呈现信息，不擅自扣除普通现金。

历史回放按出生年份推进，在现有资料最后年份之后继续架空人生。时代乱流则重排历史原型；两者都不把虚构的未来事件写成已经发生的事实。童年历史场景是家庭听闻，家长的完整投资账户不单独模拟。

## 生活与人物的边界

工作、临时收入、店铺净利润、生活费和债务会实际结算。求职与经营使用游戏化参数，没有完整地区劳动力市场或逐单进销存。未在服刑的成年人即使没有本金，也保留零工、求职、休息和学习等行动；服刑阶段提供免费的学习、反省与家书行动。

人物资料、对白、家庭状态和关系选择进入叙事。伴侣、子女、亲友信任与照护会影响实际状态和费用，但这不是自由对话系统，也没有为每位配角实现独立生活模拟。人物介绍中的整段人生与愿望属于编剧设定，不应一概解释成可执行任务。

健康和压力影响成长及后记。本作不使用随机暴毙结束贫困玩家的人生，也没有完整疾病诊疗、寿命或医疗保险模型。

## 案卷、服刑与责任的边界

新增 24 张灰黑产、网赌、法律后果、服刑和重返生活事件。七类案件按固定回合推进线索、调查与裁定，刑事案件产生刑期；三类法律责任分别记录罚款、退赔和违法所得追缴，未付部分进入债务。案件与阶段不是由玩家读完哪一页来决定，不会通过跳过剧情逃脱。

这是抽象的虚构后果系统，没有真实取证、律师辩护、庭审、上诉、数罪并罚、减刑、司法执行或法定金额计算。`gambling` 描写个人参与的行政处理个案，`misleading_ads` 描写行政营销个案，不能推出所有同类现实行为只承担行政责任。刑事选项在文本中说明明知、组织或主动参与的前提；受骗投资不会自动立案。

服刑暂停外部行动、工资与经营收入，保留持仓和债务；允许狱中成长，释放后恢复生活。普通事件和预约延期，世界冲击仍在相应时代作用于旧敞口，新闻阅读可延后。时间推进会切到剩余刑期月份，因此服刑周目的回合数可能改变。没有完整监狱劳动、探视、服刑奖励或刑事制度模拟。

相关来源、事件编号与四个新后记见 [灰黑产与服刑扩展说明](V1_灰黑产与服刑扩展.md)。全部金额与刑期是游戏规则，不是法律咨询或现实判决预测。

## 开放结局的边界

结局是当前人生的多个截面。数据中的 28 个谓词全部参与判定；默认后记保证任何正常状态都有出口。同一优先级当前以结局编号稳定排序，全部匹配结果保留，可从不同后记理解同一生。

55–79 岁的继续人生是实际功能：保留资产、债务、年龄、选择和队列，继续后面的回合。80 岁结束后重新开局是另一段人生。

`open_directions` 中的“收购”“交给团队”“下一代”等是开放式后记文案。它们本身没有实现对应的独立经营模式、家族多代模拟或新地图。安排传承的关系行动会记录你的态度与条件，不自动将父母或玩家资产复制给一个新角色。

## 本地保存与随机性

存档包含随机数状态、当前事件预定结果、事件队列、待到期回响和账本。相同种子与相同行动顺序可重放，保存后再加载当前事件不会重抽。

这是本地单机存档，不是服务器验证的竞技存档。格式校验与校验和用于识别损坏文件，不是防作弊加密。没有云端同步或真实账户资金操作。

## 已执行的逻辑核查

`node --test tests/narrative.test.js` 的叙事集成检查覆盖：

- 219 个事件、24 个分类的资格与候选调度。
- 12 家庭随机可达与指定家庭开局。
- 存档锁定结果、重复点击不重复结算。
- 78 条预约边登记、过期回响和主线跨龄保留。
- 历史日期门槛、每回合一个冲击、乱流数量及间隔。
- 完整人生直到 80 岁、12 主线齐全、同种子重复运行一致；另测刑事路线、服刑延期、释放补章与 80 岁未完刑期结算。
- 55 岁结算与继续时的资产、债务和回合保留。
- 966 个编写结果逐一经过实际 Core 执行。
- 28 个结局逐一使用真实状态字段满足条件。

另对 219 张卡执行过零现金、零可投入现金资格检查，均至少保留一个可选择分支；狱外成年基础工作、零工、求职、休息和学习在行动点可用时仍开放，狱中有专属免费行动。

v1.3 的测试、浏览器验收、真实旧档迁移和发行校验见 [交易玩法与验收](V1.3_交易玩法与验收.md)。

这些检查证明内容接入、资金与状态逻辑对应的性质，不等同于长期难度平衡、每条随机人生的人工试玩或全部浏览器的视觉验收。持续玩法平衡可以调整数据权重和参数，但不能据此宣传现实投资胜率或收益。
