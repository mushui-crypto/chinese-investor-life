# 连锁剧情与示例周目

以下 12 条是可交叉的剧情弧，不是 12 条互斥职业路线。`→` 表示可走向，只有数据中 `schedule` 字段列出的 29 条边（基础 20 条，加上扩展 9 条）是结果触发的预约；其他边由状态与玩家主动领域选择进入候选池。预约不会绕过年龄、资金、人物和资产条件。

预约到期仍不满足条件：暂不显示，等待到 `expires_after_turns`；到期记入档案“这次机会未能继续”，不罚钱、不补造状态、不循环重排。后续可通过其他有效事件重新获得同类机会。旁白只说机会没有继续，不假定项目成功或失败。

## C01｜三千块的神（股票→期权→名声→再选择）

MAIN04 → STK01 → OPT01 → OPT05 → FAMO01 → FAMO02。

第一笔小赚给玩家“我看懂了”的体验，罕见的期权大胜带来夸张身份反转。OPT01 大胜会预约 OPT05，逼近“刚赢了还要不要继续”这个问题。FAMO01 公开成功后会引来付费群邀约。

分叉：保留成果可到 E02；继续扩大可能到 E01/E05；名气高但钱不多到 E19；诚实讲述到 E20。不能保证每位玩家都必经百倍：这条弧需要对应随机结果。

## C02｜我以为我跑得够快（资金盘→回款→复投→关系）

PON01 首次真实回款 → PON02 → 复投失败到 PON04；介绍熟人则 PON05；再次追加冻结可到 PON07。

三次诱惑不同：第一次是证明能拿到钱，第二次是更高额度，第三次是追回已经损失的钱。PON07 的二次诈骗不提供真实操作办法，只呈现再付费与停止付款的选择。

分叉：及时停止不自动发财富结局；等待追偿可到 E11；介绍人若失去信任到 E12；履责与修复后可到 E08/E18。受骗身份不能自动抹去向亲友做过的承诺。

## C03｜前贵宾，现骑手（高点→归零→工作→生意）

任意市场权益真实归零 → REC01 → JOB02 / REC02 → REC04 → BUS07。

REC01 求职成功会预约排班事件；REC04 小生意成功预约扩张。第一幕不要求玩家先交培训费。富裕家庭可求援，但额度有限，家人也可拒绝。

分叉：手艺路线 E07；小店 E06；大幅重建 E03；仍负债工作 E10；再度全押失败仍保留 REC 和基础行动入口。

## C04｜账面身价一亿（天使→估值→稀释→退出）

ANG01 → ANG03 → ANG04 → ANG06 → ANG08。

只有实际成功融资等结果才预约下一站。新增出资进入锁定权益，不直接成为现金。上市准备不等于上市完成；ANG08 只有可售权属时才能卖。锁定到期后的实际退出由权益模块登记 `equity_exit`。

分叉：纸面富贵 E04；仍在等待 E13；真实变现 E14；项目失败后可通过 JOB/REC 开新生活。出生富裕只能更早达到门槛，不能更早拿到已知结论。

## C05｜兄弟之间不需要合同（青春→合作→分配→担保）

YOU05 的共同豪言 → 成年后 BUS04 → BUS03 → DEB05 → REC07 / REL05。

青春约定延迟 8 回合出现，仍检查年龄。合作前可选择写清条款或不合伙；不合伙不自动结束友谊。签担保后若被追索，才生成相关债务，不因为“兄弟”二字自动减钱。

分叉：一起经营、利益分开、成为债务关系、几年后重新见面。修复关系不强制重新合伙。

## C06｜额度养出来的雪球（申请→到期→协商→循环）

DEB01 获批 → DEB03 → 协商失败可预约 DEB04 → DEB06 → DEB08。

新贷款不提高净资产，授信检查累计余额、偿债比与用途。协商成功只是改变期限；遇到拒贷、无本金、信用差时，工作与求助仍可选。

分叉：如期清偿 E08；履行协商 E09；未清偿但有职业 E10。任何结局都不会自动删除剩余合同。

## C07｜收银盒比 K 线实在（摆摊→订单→现金缺口→扩张）

BUS01 成功 → BUS03 成功 → BUS07 → BUS05 / BUS06 / BUS08。

关键反转是订单大涨仍可能缺钱：预付款、备货、工资、回款日期分别记账。扩大经营要付钱，不能只点“扩大”就得到永久利润。

分叉：经营三家且正现金流 E15；保留小规模 E06；出售资产后转职业；创业失败也不强制金融投机。

## C08｜你还有空回家吗（机会→隐瞒或沟通→关系）

MAIN07 → REL02 → REL04 / REL06 / REL08 → REC07。

按实际家庭成员替换人物。共同财务需要知情边界；支持冒险与拒绝被隐瞒可以由同一个人同时表达。玩家没有伴侣子女也能进入照护者与朋友关系线。

分叉：财富高但关系疏离 E17；修复后 E18；储备与关系都较好 E16。亲情不是一次送钱就买满的数值条。

## C09｜全网最懂的人（截图→包装→旧事→自传）

STK08 大胜 → FAMO01 → FAMO02 → FAMO05 → FAMO06。

提供从头到尾诚实的成名路线，也提供沉迷人设、名气反噬的路线。不能将“做内容”全写成骗人：真实经验、失败记录和专业工作都可以产生正向关系。

分叉：名气大于财富 E19；愿意认错的公众人物 E20；主动离开公开舞台；经营自己的实际业务。

## C10｜最懂风险的人，也遇上风险（知识→机构→相关性）

FND05 / OPT03 → FAMO07 → HST05 / HST16 / HST22 → FAMO08。

历史回放必须按年份，以上历史冲击不是一个人的必经顺序。时代乱流每局最多选其中若干模板。知识降低误解，不保证永远有流动性。

分叉：成功进入 E01；高位回落 E05；改变策略并保持财富；回到普通职业。不能为了教育玩家而暗改概率让专业路线必败。

## C11｜够了吗（守成→比较→再下注或停手）

MAIN10 → LATE02 / LATE04 → LATE07 → LATE08。

主动停止新增高风险投资需要在行动面板单独确认并保留两回合记录，然后才产生 `voluntary_exit`。不是点一次休息就直接发“封盘”结局。继续下注也允许成功，晚年不是必输关。

分叉：E23 主动退出；E01 继续扩张；E21 健康恢复；E24 尚未整理完的人生。

## C12｜把下一章交出去（关系→接班→传承）

LATE01 → LATE03 → MAIN11 → MAIN12。

有子女走亲子，有学徒走手艺，二者都没有则整理自己的记录。遗产只能转移实际可转移部分；家族关系、声誉和未完成责任成为下一代背景，债务依架空规则与权属处理，不自动给未签约孩子背锅。

分叉：E22 后代自主、E16 家庭安稳、E17 关系疏远，或 E24 自己仍在继续。

## 三个完整周目梗概（编剧样例，不是随机模拟实测）

### A｜你们别急，我真不是骗子

县城工薪开局，成年拿到 8,000 元。先做工作攒钱，有限参与股票，后来一次期权罕见大胜。阿豪替你转发截图，全网叫你老师。你接受一次公开采访，拒绝不透明挂名；把工作保留一段时间，之后用部分现金经营自己的业务。

中年时一次市场危机让账面大幅回撤。你没有失去所有资产，家人却开始担心。公开完整经历后热度降低，有一批人继续关注。六十岁结算可落在 E20，并显示职业与关系后记。继续方向可以是带新人，也可以是重新做一个产品。

这条路线证明：爽文大胜可以守住，不需要系统强制安排爆仓来完成说教。

### B｜谁还没当过几天大哥

拆迁家庭开局，成年赠与较多。买高波动资产、参加晚宴、被介绍进更大圈子。一次投资真实变现，另一些项目只有纸面估值。玩家把纸面身价误认为可用钱，扩张经营并签有限担保。危机来了，股权锁定、经营回款延期、担保被追索叠加，进入流动性与债务剧情。

选择求职与零工度过缺口，在招聘会遇见旧圈子的人；没有自动清空家庭储备，不能凭空重置负债。通过手艺和一家小店重建。晚年可能是 E06/E08，也可能尚在 E09。旧西装还在箱底，玩家可以自己决定是否再穿。

这条路线的戏剧来自不同现金周期相撞，不是每次危机统一“资产-90%”。

### C｜没成为传说，也没停在原地

经济困难家庭开局，成年没有赠与。先求职，失败后做零工，再参加基础岗位。曾被资金盘推介吸引，拒绝参加后仍可与朋友来往。多年后用积蓄开小生意，第一次失败，第二次通过实际客户需求站稳。

孩子或学徒想走自己的路，你没有要求复制自己。六十岁后仍有投资入口，也可以主动结算。可能进入 E07/E22/E24，后记记录真正的劳动、关系和选择，而不是以“没赚到一亿”判负。

这条路线保证零本金可完成一生，也给低风险玩家足够内容。

## 三个关键戏剧镜头

**赢。** 结算前屏幕停一拍，数字落定，先显示“已实现”，再出现人物消息。阿豪：“你不是吧？你真拿住了？” 玩家能马上分配收益，不强制继续押。

**输。** 强平通知停在屏幕，窗外早餐摊正在开门。房租、联系人、工作机会同时存在。按钮至少包含“找一份工作”“开口求助”“整理剩下的账”，有条件时再给借款和经营。

**回来。** 旧熟人进店：“你现在做这个？” 主角看一眼已经结算的营业款：“嗯。今天开门。” 不宣布从此永不失败，让玩家继续做下一次决定。


## v1.1｜从“最后一把”到重新开始

UG01 参赌 → UG02 追损 → UG03 明知组织推广；也可从 UG04/06/07/08 进入其他明知参与的刑事路线。任何邀请都可以拒绝，单纯受骗的 UG10 → UG09 只生成受骗与追偿。

案件由 Core 独立推进，LAW01 调查 → LAW02 刑事裁定或 LAW04 行政处理 → LAW03 未履行责任。以上是系统阶段通知，不全部计入 29 条剧情预约边；不点击配合或关闭剧情不会停止案件。

进入服刑后只安排 JAIL01–JAIL04、相关法律事件和适配过的晚年章节，普通机会延期。释放时进入 RE01，再通向 RE02 求职、RE03 拒绝旧诱惑、RE04 重新生活。E25 保留铁窗与未完刑期，E26 保留退赔债务，E27 记录出狱后的真实就业，E28 记录有参赌经历后的退出。无参赌经历的首次拒绝不会伪造戒赌史。
