# 市场准入与现实参考

核对日期：2026-09-22。游戏采用虚构城市与简化时间，不提供现实开户通道。以下条件是游戏规则；实际开户由对应机构和现行规则判断。

| 游戏市场 | 首次开放条件 | 说明 |
|---|---|---|
| 基金 | 18 岁 | 最低投入 1,000 元为游戏份额设计 |
| 一般债券组合 | 18 岁、眼力 15 | 简化债券品种，不代表所有债券都向普通个人开放 |
| 股票组合 | 16 岁完成家庭认知故事，18 岁开放交易 | 游戏统一成年后投资，订单金额不是现实统一开户资金线 |
| 期权交易（买方、卖方共用） | 18 岁、自有金融资产 50 万、眼力 40、经验 6 个月 | v1.39 合并两侧开通条件；买方支付权利金，卖方缴纳保证金，赔付规则分别保留 |
| 杠杆合约 | 同期权交易 | 以金融期货准入难度安排层级；不能推及全部商品期货、外汇、加密合约或境外产品 |
| 房产 | 18 岁、自有金融资产 20 万 | 游戏准备门槛；真实限购、首付、按揭审查随地区与机构变化 |
| 天使直投 | 18 岁、自有金融资产 300 万、眼力 60、经验 12 个月 | 300 万是游戏门槛；天使直投不等同私募基金，没有据此宣称统一法定门槛 |
| 加密经历 | 18 岁，经大学室友或社会关系完成认知故事 | 虚构特殊经历，不表示境内合法开户资格 |
| 加密合约 | 18 岁、眼力 45、完成加密认知故事 | 无模拟练习次数要求 |
| 资金盘接触 | 24 岁、经历一次熟人推介剧情 | 没有合法的“资金盘投资资格”，仅为骗局剧情入口 |
| 虚构网赌 | 20 岁，经大学同学、室友或社会关系完成接触故事 | 只表示剧情入口，不是现实资格或安全建议 |

自有金融资产＝个人现金＋未冻结的股票/基金/债券/期权/合约资产－全部债务本息，最低记 0。家中储备、商铺、房产、天使估值、加密资产、资金盘与债权不计入。扣除全部借款是游戏的保守简化，不能借一笔钱直接跨过资金门槛。

参与经验从首次模拟练习或金融投入开始累计。模拟练习为自选活动，不是市场开放条件；免费，占 1 次安排，眼力 +10；普通学习也能提高眼力。实际首次投入通过检查后记录已参与权限，亏损后保留经历；实际现金、行动点、服刑和封盘仍逐单检查；生活费预留仅作提醒。旧存档已有持仓和实际参与过的剧情产品保留，不出售旧仓、不改随机结果、不补发收益。

## 现实资料与具体区别

- [上交所：期权投资与开户](https://one.sse.com.cn/onething/qqtz/)：包含资产、相关经验、知识测试、模拟交易、风险承受及诚信等要求，并有权限分级。游戏不是完整复制：采用当前资产替代规定期间日均资产，用眼力简化知识要求，取消模拟次数门槛，半年/一年经验替代具体经历审核。
- [中金所：交易者适当性制度管理办法](https://www.cffex.com.cn/u/cms/www/202003/271635174xwg.pdf)：金融期货的资金、知识和仿真/实盘经历要求。游戏合约包含多类历史原型，统一 50 万是玩法分层，不是对所有标的现实准入的断言。
- [中国证监会：投资者问答](https://www.csrc.gov.cn/csrc/c100211/c1452137/content.shtml)：私募基金个人合格投资者有金融资产或收入条件，并有单只基金投入要求。天使直接股权投资与私募基金认购不是同一行为，本作天使门槛仅借鉴风险承受概念，没有把私募条文直接套到天使直投。
- [中国结算：证券账户业务指南](https://www.chinaclear.cn/zdjs/zzb/202503/b78cc0f35bc84423bb87b0a0806b4731/files/8.%E4%B8%AD%E5%9B%BD%E8%AF%81%E5%88%B8%E7%99%BB%E8%AE%B0%E7%BB%93%E7%AE%97%E6%9C%89%E9%99%90%E8%B4%A3%E4%BB%BB%E5%85%AC%E5%8F%B8%E8%AF%81%E5%88%B8%E8%B4%A6%E6%88%B7%E4%B8%9A%E5%8A%A1%E6%8C%87%E5%8D%97.pdf)：实际规则包含特定未成年人情形。本作统一以 18 岁作为简化边界，不模拟例外审批。
- [人民银行等八部门：银发〔2026〕42 号](https://www.pbc.gov.cn/tiaofasi/144941/3581332/2026020619591971323/index.html)：2026 年通知已替代 2021 年通知。涉及的境内虚拟货币业务活动受到严格禁止，玩家在剧情中接触不意味着存在正规境内开户路径。
