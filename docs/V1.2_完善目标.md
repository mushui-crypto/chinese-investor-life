# v1.2 完善目标与验收依据

用户授权：一次性完成前述六个优化方向，做到完整、可玩、协调并经过验证。

1. 全屏场景与面板：保留全屏背景；人物有独立可见区域；读事件时折叠无效安排；近期记录可折叠；移动端可读可点。
2. 人物与人生变化：房间不包含固定年龄人物；独立角色覆盖童年、青年、中年、老年，并以衣着/姿态反映富裕、低谷与服刑；人物资产保存项目内。
3. 重大事件演出：第一笔大钱、真实投资归零、判决与释放有不同呈现；全部依据已结算状态；可跳过，减少动态有效，刷新不重复扣款。
4. 选择代价：选项在点击前给出本次投入、生活预留、债务/锁定/不可逆责任等可计算信息；不得提前泄露已经锁定的随机结果；实际执行与预览一致。
5. 熟人后续：至少三位现有人物有可追踪的连续往来与分支；早年选择影响后续邀请、关系与重逢；人情页能看到真实发生的共同经历。
6. 人生节奏：普通账目合并为可读本期小结；重大选择保留独立阅读；降低后期无关抽卡密度；剧情队列不会丢失关键章节、预约或司法通知。

保留已有全部市场、借贷、法律后果、服刑、28种后记、三槽存档与旧版本迁移能力。新增叙事状态必须被保存、验证、重放。

最终证据：针对性自动测试、全部内容校验、完整人生/服刑浏览器回归、旧包真实存档迁移、桌面与窄屏截图、项目内美术来源与提示词、最新可运行dist和发行包。

追加方向（用户连续补充）：投资市场按年龄、资产、经验逐步开放，显示当前差距；统一全局可读性与可玩性。成年后约 70% 的设计重心在投资市场，包含观望、复盘和持仓管理，另外约 30% 为人生事件；这是默认节奏目标，不强迫玩家按次数交易，也不将童年或服刑阶段硬算进投资占比。
