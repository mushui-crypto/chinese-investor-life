# v1.50 日常插图与操作卡片

## 场景跟随实际时间

修复上一项活动完成并推进时间后，插图仍停在旧活动的问题。例如大学生午休后到 13:00，显示阅读室自习；上班结束进入午饭，显示饭点；加班或晚班到 22:30，显示准备睡觉。

正在看盘的选择保留当前时段的插图；开始下一时段或第二天后，旧选择不再覆盖新场景。旧存档没有场景信息时按当前身份、时间恢复，不从历史文案猜测事件。

## 身份、地点与事件核对

| 情况 | 场景处理 |
| --- | --- |
| 大学生上午 / 下午 | 课堂 / 阅读室自习，下午不再出现讲课老师 |
| 在职职员 | 白天办公；摸鱼才切换办公室行情画面 |
| 请假、旷工、明天入职 | 在家休息，不显示正在上班 |
| 待业 | 上午求职；不会默认坐在办公室 |
| 自己经营小店 | 整理货物与订单，不默认投简历 |
| 退休 | 外出日常，不默认上班 |
| 地铁通勤事件 | 车厢内的职员、手机和扶手，替换街边买菜图 |
| 白天 / 傍晚 / 深夜电话 | 分别使用日光、夕阳、夜间灯光版本 |
| 22:30 准备睡觉 | 夜色卧室、熄屏电脑、放下手机；不再压暗白天沙发图 |
| 夜间复习 / 看行情 | 根据玩家选择分别显示灯下读书 / 夜间电脑 |
| 拒绝回电、说明按点下班 | 离开通话或工位场景，不继续表现已拒绝的动作 |
| A 股开盘前、午休、收盘后 | 对白明确消息、上午记录、收盘复盘，不声称实时价格仍在变动 |

场景读取不消耗随机数、不改变资金、属性或结算。日常事件保存日期、时段与选择，仅在对应时段内保留场景。

## 六张新插图

使用内置 image_gen 生成，并转换为 WebP 供游戏加载。提示词记录：[V1.50_daily-scenes.json](art/V1.50_daily-scenes.json)。

- `public/assets/daily/study-day-v1.webp`：白天阅读室自习。
- `public/assets/daily/study-night-v1.webp`：夜间灯下复习。
- `public/assets/daily/bedtime-v1.webp`：睡前放下手机，按反馈重新生成双手姿势。
- `public/assets/daily/commute-v1.webp`：地铁通勤。
- `public/assets/daily/phone-day-v1.webp`：白天通话。
- `public/assets/daily/phone-night-v1.webp`：深夜通话。

原始 PNG 保留在同目录；发行包使用 WebP。

## 操作卡片与窗口

标题与属性描述作为一组靠顶，时间靠底；同一行卡片等高。桌面三个活动横排，长描述自然换行。矮桌面窗口压缩操作区并调整背景取景，保留人物、手部与主要道具。手机宽度按两列折行，同排仍保持上下对齐；长操作区内部滚动。

## 验证

- 65 项定向测试通过：真实活动推进、事件分支、就业与请假、跨日、旧档和存档校验。
- 独立端口导入测试档，实际点击午休到自习、夜间复习事件，核对通勤、夜间电话及重绘的睡前双手。
- 浏览器核对 1864×1230、1280×720、390×844；同排卡片标题与时间对齐，页面无横向或纵向溢出。
- 截图与测试结果在 `reports/v1.50/`。
