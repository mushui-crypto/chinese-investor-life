# 中国式赌狗 v1.1 · 灰黑产与网赌扩展验收

版本：1.1.0。日期：2026-09-22。运行方式：本地浏览器单机。

## 本次变化

新增 24 个事件、72 个选项、87 个结果和 4 个开放后记。总内容为 204 个事件、614 个选项、910 个结果、29 条预约边、28 种后记。

新增网赌参赌与追损、明知推广网赌、出租账户协助犯罪、欺诈项目、转卖个人信息、非法集资和误导营销的虚构情节；单纯受骗、拒绝邀请、停止参与各有对应记录和后续。

“人生案卷”显示行为、线索、调查和裁定。调查前不泄露未来判决金额；未付追缴、罚款及退赔分别计入债务，同一案件不重复结算。刑事路线会进入服刑阶段：外部求职、经营、借贷、交易与关系安排停止，已有资产和债务继续按规则结算；狱中可学习、反省或写家书。服刑结束后可以重新求职，尚未履行的责任仍然保留。

普通人生节点在服刑期间延后，重大晚年章节使用狱中正文，80 岁仍未服完刑期可以形成开放后记。新增监室手绘场景和手机布局。

所有案件金额、处理节点与刑期都是虚构游戏规则，不是现实个案的司法结论。当前规则按案件类型固定参数，不模拟完整司法程序。详细边界与参考来源见 [扩展说明](V1_灰黑产与服刑扩展.md)。

## 兼容与使用

刷新同一地址 `http://127.0.0.1:4173/`，选择原存档即可继续；成年后按条件遇到新事件，不必重开人生。旧档先验证原始校验和，再增加空案卷等默认字段，不重抽当前事件结果、不改变现金或既有借款。

`npm run build` 生成 `dist/`，运行方式仍为 Mac 双击 `启动游戏.command` 或执行 `npm start`。新版发行包为 `中国式赌狗-v1.1.zip`，旧 v1.0 包保留。

本版继续使用浏览器本地存档。换端口、浏览器、电脑或清理浏览数据前先导出。手机验证使用桌面 Chrome 的尺寸模拟，未声称已在真实 iPhone 或 Safari 上验收；长期平衡仍需更多试玩。
