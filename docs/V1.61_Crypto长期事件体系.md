# v1.61.0 · Crypto 长期事件体系

沿用已有事件池、人生时钟、随机种子、持仓、贷款、账本、存档与人生后记。原有弹珠、学生旧事、网赌和人生事件保留。新增 CL01–CL42，事件之间不写固定预约，不自动替玩家投资。

## 穿插人生

四个可交叉分支：现货、山寨币、合约、高收益项目。新增故事使用澄光币（CLG）、赤尾币（CHI）、币易交易所与长灯计划；既有交易市场及旧持仓兼容保留。

每个节点使用 requiredState、blockedState、weight、cooldown、minDelay、ageStage、memoryTrigger。Crypto 与网赌共用普通人生事件计数，相邻两条风险故事之间至少经过 90 天及 2 件普通事件。拒绝或退出后至少冷却 180 天，重复节点另有自己的冷却。每个成年人生阶段提供一个现有随机故事名额，人生主线仍优先；同池权重避免长事件库把已发生的经历完全淹没。

普通工资、失业、伴侣、买房、孩子及工作故事读取实际身份、工资到账或家庭状态。REL02 和 ENC_JOB03 根据真实 Crypto 经历增加关联选项。普通生活不会自动转钱。

## 金额与记忆

初次投入 100 元成为实际持仓。涨跌读取真实报价；涨 20%、翻倍、跌 30%、回本、爆仓和后来方向正确均有对应持仓或成交前提。结果回执只显示已经发生的现金与资产变化，不再重复发放收益。

现货、山寨和合约复用交易系统。合约沿用游戏已有的日内结清规则，后续事件回忆已结算交易。取回本金会按真实可卖份额扣除费用；普通事件卖资产还债也同步成本与长期交易记录。新的虚构币价格使用独立派生波动，不改变原币种的随机序列。

长灯计划加入后每 30 个实际生活日支付一笔收益，前半年可正常支付；追加本金从追加日开始计收益。之后可能出现预警，玩家实际看见预警并选择后，才可能进入后续冻结与失败阶段。预警后仍有真正取回本金的路径。冻结金额不计可兑现资产；失败只记一次损失。已经退出的项目可以在普通人生间隔之后传来坏消息，不再扣钱或再次退款。

长期经历存放在 behavior.cryptoLife，与网赌分开：首次买入、盈利、亏损、山寨大涨、合约、强平、项目到账与预警、退出与复入等记忆。旧存档仅承接可验证持仓，不补造丢失的首次年龄与历史金额。

## 退出与结局

全部卖出现货、取回项目本金、降低合约风险及永久关闭合约均能实际执行。所有重要节点提供不新增投入的选项。没有持仓且连续两年不参与，进入 CRYPTO_EXITED；普通下单入口不再新开仓。后来偶遇上涨时，只有玩家在 CL39 明确选择复入才重新参与；CL40 只有“哦”。永久关闭的合约不随复入重开。

13 类阶段后记由真实经历生成，12 项黑色幽默成就由实际选择、持仓或成交记录触发。阶段后记不清空资产、不强制结束人生。

E34「Crypto爆仓破产」仅在曾经高倍、追损、为 Crypto 借债、山寨币及项目风险叠加，已实现严重损失且实际净资产不大于零、仍有债务时进入总人生结算。钱包、债务与持仓保留真实数值，不为了文案人为归零。存档会核验这个结束条件。

## 界面与复盘

Crypto 插曲使用屏幕下方文字区，沿用现有纸色、墨绿按钮与两列选项；窄屏单列。没有为这些插曲套用不相关的大图。人生小记与总人生结局可查看累计投入、实际回款、已实现盈亏、浮盈亏、最高持仓、最终资产与债务、合约胜负、退出及复入、关键选择和成就，并可随人生小记导出。

## 验证入口

- `npm test`：事件资格、真实财务、存档、退出、结局及既有功能回归。
- `npm run check:content`：目录、条件、效果、选项和结局静态检查。
- `npm run qa:crypto-life`：隔离浏览器存档，1280/1440 桌面与 390 窄屏检查。
- `npm run qa:crypto-pacing`：多种种子的整个人生抽样。仅使用明确记录的现金和健康续航夹具；不强造 Crypto 报价、盈亏、状态或指定后续事件。

测试夹具和采样报告保存在 tests、scripts 和 reports/v1.61.0。随机人生抽样不保证每一局遇见全部事件；所有候选分支另由条件与财务专项测试覆盖。

发布验收：899 项自动化测试通过，18,340 项内容校验无错误；26 项浏览器检查覆盖桌面、窄屏、实际买入与卖出、存档重载和结局复盘。32 个人生样本全部推进至 80 岁，无账本或事件间隔错误，实际随机遇到 27 类 Crypto 节点；稀有节点不以自然抽样保证出现。

兼容核对：原 353 个事件、1,131 个选项、2,406 个结果均保留；原有学生旧事、弹珠和 27 个网赌节点内容未改动。现有币种报价及共用随机序列的回归通过。发布构建只包含运行所需文件，测试脚本和采样报告保留在开发项目中。
