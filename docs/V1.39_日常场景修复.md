## 交易用语

| 产品 | 开始交易 | 结束交易 |
|---|---|---|
| 股票、债券、加密现货 | 买入 | 卖出 |
| 基金 | 申购 | 赎回 |
| 杠杆合约、加密合约 | 做多开仓／做空开仓 | 平仓 |
| 期权买方 | 买入开仓，选认购／认沽 | 卖出平仓 |
| 期权卖方 | 卖出开仓，选认购／认沽 | 买入平仓 |
| 天使股权 | 认购股权 | 转让股权 |
| 房产 | 购买房产 | 出售房产 |
| 资金盘 | 投入 | 申请提现 |

下单区、持仓、资产页、成交通知、费用和错误提示共用同一套交易用语。合约金额改称名义持仓金额，风险说明使用盈亏、保证金和强制平仓。实际费用和结算方式未改。

## 期权开通条件

买方与卖方统一为：年满 18 岁、自有金融资产 50 万元、眼力 40、参与经验 6 个月、模拟练习 1 次。市场列表只显示一组条件。

旧存档已开通过任意一方，即可使用两种交易方式。权限共享，产品和持仓仍分别记账；权利金、保证金、最低金额、实际现金、到期和超额赔付规则保留。
