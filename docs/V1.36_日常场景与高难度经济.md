# v1.36：日常场景与高难度经济

生活安排以场景为主，工作收入更少，生活开销更重。可以继续冒险，也可以变现、借钱和重建，但打工不再是一点就能补回大笔本金的按钮。

## 少一点窗口，多一点人在生活里的感觉

- 日常选择直接放在右侧：上班、摸鱼、零工、吃饭、休息与熬夜会切换主场景，不再每次弹出一整页安排。
- 已读主线、收支回执与旧账收进近况记录；真正待选的故事仍正常出现。
- 现金余额只常驻一处。资产、债务可展开，完整生活费金额仍能从账单说明查看，下单区的风险提醒保留。
- 左右 HUD 避开中央人物、双手与电脑。窄屏展示完整场景，并在活动旁提供下一步按钮。
- 新增 12 张原创日常背景，带短过渡、屏幕微光或蒸汽；不是人物骨骼动画。系统或游戏内选择减少动态时停用动效。

全屏日常图约 16:9；事件卡继续 3:1。内置 imagegen 生成，原始 PNG 与运行用 WebP 存于 `public/assets/daily/`；[完整提示词与素材来源](art/V1.36_daily-scenes.json)。

## 收入下调

以下是游戏标尺，用来表达“小城收入、大城市开销”，不是现实收入统计。

| 来源 | 新规则 |
| --- | --- |
| 固定岗位 | 月薪 ¥2,200–¥4,200，随本事变化；工资随时间到账 |
| 认真打工 | 整天 ¥80–¥120，完成就到账 |
| 接点零活 | 整天 ¥80–¥100，完成就到账 |
| 半天零工 | 半天 ¥40–¥60，完成就到账 |
| 加班 | 1/5 日薪，最多 ¥25 |
| 熟人成长加价 | 动手成长方向每期首次整天接活加 10% |
| 熟人介绍岗位 | 月薪 ¥2,800 |
| 短训上岗 | 月薪 ¥2,400，材料费仍为 ¥200 |
| 出狱试工 | 三天共 ¥240，之后月薪 ¥2,200 |
| 维修单 | 三天交付 ¥300 |
| 社区临时班 | 一次 ¥100，原有一次性限制保留 |
| 老客订单 | 先付 ¥300 备料，四天后回款 ¥700 |
| 普通劳动剧情 | 34 个收入结果由 ¥12,000 / ¥4,000 调低到 ¥600 / ¥150 |
| 剧情临时零工 | 38 个收入结果由 ¥6,000 / ¥1,000 调低到 ¥100 / ¥40 |

几个日结入口共用一天的接活时间：一整天，或两份半天。不能在做完半天零工之后，再从旧入口接一整天；换页与读档不恢复次数，新交易日恢复。疲劳达到 65 仍会降低劳动收入，养老金不额外扣疲劳。

原先按人生回合一次性支付的大批工钱彻底取消。开店起始月净利润由本金的 1.8%–3.8% 降为 0.8%–1.6%，照看生意的利润增幅由 12% 降为 6%；订单变化、库存损失、投资涨跌和家庭赠与仍沿用原有规则。

## 开销上调

| 年龄 | 每天基本开销 | 每月（30 天） |
| --- | ---: | ---: |
| 18–24 | ¥150 | ¥4,500 |
| 25–34 | ¥180 | ¥5,400 |
| 35–44 | ¥210 | ¥6,300 |
| 45–54 | ¥230 | ¥6,900 |
| 55–64 | ¥210 | ¥6,300 |
| 65+ | ¥190 | ¥5,700 |

伴侣每月加 ¥900，孩子加 ¥2,000，55 岁后照料长辈加 ¥900；自有住房每月减 ¥1,200。饭钱、住处、交通与日用品已经包含在基本开销内，生活档次另算。未成年仍由家里承担。

突发修理、医疗、搬家等维持原来的间隔与次数上限。生活费继续只提醒，不冻结投资现金；梭哈后的账单、欠款、资产变现与七天求生流程保留。

普通工资通常不足以独自覆盖开销，零工也不保证救回零现金开局。玩家需要积蓄、资产收入、家人援助或其他周转；所有已有借款仍需偿还。

## 旧档与结算

- 一次性降低旧岗位的未结算工资，并限制在新岗位上限内；旧养老金、尚未交付的劳动报酬与正经营利润同步转换。
- 既有现金、负债、持仓、随机状态及过去账本保持不变，负经营利润不因迁移减轻。
- 已付工资不追回，未结算的天数按新工资算；历史生活费不追补，后续按新费率结账。
- 转换标记随存档保存，再次读档不继续打折。

## 验证记录

- 375 项单元测试通过，含跨入口接活额度、报酬、工资迁移、日账与期账不重复、现金不足、梭哈和求生。
- 10,657 项内容检查通过。
- 476 项浏览器检查通过：新场景与生活页 112 项、小时玩法与 10 个市场入口 297 项、剧情阅读 67 项。测试范围为 320–1920 像素宽，包含手机下一步、读档、信息说明、工作跳转、固定栏、图片解码及减少动态。
- 固定种子的 30 天预算：年轻人减少 ¥2,095，普通职员减少 ¥2,345.20，熟练职员减少 ¥2,588.20，有孩子的中年人减少 ¥5,843；包含这些种子实际触发的临时账单，不代表所有局的均值。
- 零现金、无资产援助的三种局（不工作、每日零工、普通固定工资）均在七天欠费后进入原失败结局。充足本金的独立年龄推进样例经过 80 个成年阶段到达 80 岁，验证没有机械卡死；这不是普通玩家通关率。
