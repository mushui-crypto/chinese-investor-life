# v1.34 日常时间、人生节奏与市场界面

本版把成年后的每一天接到同一个时钟：工作、交易和睡觉都发生在这一天里。保留“先过日子”，无需把一生逐小时点完。

## 一天怎么过

| 时间 | 可以做什么 |
| --- | --- |
| 07:00 | 吃早饭，或醒来先刷行情 |
| 09:30 | A 股上午盘；有工作可以认真上班或摸鱼看盘 |
| 11:30 | A 股午休；午睡、散步，可能遇到同事聊收益 |
| 13:00 | A 股下午盘；继续上班或边干活边交易 |
| 15:00 | A 股收盘，可以活动一下或查看账户 |
| 18:30 | 下班；学习、见朋友、回家休息；可能收到加班安排 |
| 22:30 | 正常睡觉，或继续熬夜到次日 02:00 |
| 次日 02:00 | 加密仍可交易，之后睡觉结算这一天 |

A 股买卖只在上午、下午两个时段开放，T+1、整手、费用和真实现金检查继续有效。收盘后 A 股报价保持不动。加密在收盘后仍有行情变化，也可继续买卖；日内合约在睡觉结算时结清，原有逐仓强平仍会中途发生。

开盘时段参照[上交所交易时间](https://english.sse.com.cn/start/trading/schedule/)，游戏合并了集合竞价。采用虚拟本地日历，每天均可体验交易；本版没有模拟周末休市、节假日、港美股时区和夏令时。不要将游戏时钟当作现实交易日历。

## 工作、休息与熬夜

每个时段至多选一项日常活动，不扣原有的生活安排次数。活动可以跳过；加班等已弹出的选择需要先处理。未就业时不会出现认真上班、摸鱼和加班选项，仍可学习或休息。

- 认真上班：本事 +1、疲劳 +3。工资随每日结算到账。
- 摸鱼：疲劳 +4、压力 +1。每个工作时段第一次摸鱼或实际下单会检查一次，有 25% 的游戏概率被发现；被发现压力再 +4，当天工钱少 25%。刷新、读档、换市场不重新检查。
- 加班：有岗位时，下班有 25% 的游戏概率收到临时加班。接受后占用晚间时段，到 22:30，多拿四分之一日薪，疲劳 +14、压力 +4；拒绝压力 +2。加班收入独立记账，只发一次。
- 熬夜：睡下后疲劳 +24、压力 +5。第一晚身体 −1，连续第二晚起每晚身体 −3。疲劳和连续熬夜记录写入存档，不在第二天起床时清零。
- 正常睡觉：疲劳 −12，连续熬夜归零。原有每日疲劳自然缓解仍保留。午休、散步和休息可进一步改善状态。
- 疲劳达到 65，固定日工资和零工收入减少四分之一。固定工资的疲劳扣减与摸鱼扣减不叠加。今晚的睡眠变化记在当日工资结算之后，影响次日状态；次日休息可缓解。

日常事件还包含通勤受阻、同事晒收益、家人电话。事件在进入对应时段时抽取并保存；进入页面、打开说明不会重新抽取。所有选择先显示具体属性代价。上述概率、属性和工资处理都是虚构游戏规则。

开始按小时生活后，原有“认真打工”“接点零活”按当天小单报价，完成后立即到账；不会因为进入新回合恢复成整批工资。固定岗位工资、临时零工与加班分开记账。

## 少点空白时间

“先过日子”一次最多推进 30 天，逐天算行情、工资、生活费和债务。消息、约定、工作交付、账单及持仓明显变化会让它停下。已选择的熬夜照常结算；未安排的日子按正常作息过，不主动下注、下单或替玩家卖出持仓。

移除主动交易只有三天的旧限制，每个游戏日恢复市场操作次数。已持有合约到期、强平与项目归零照原规则发生。部分上头、追本、熬夜与工作支线可在新的经历后再次出现，仍有间隔，不靠空点和读档反复触发。

生活费继续只是提醒，可以用全部实际现金下单；之后照常承担账单和求生后果。原有网赌清算尾声与其他投资结局没有改写。

## 市场界面

全部 11 个交易室视图（10 个入口，期权买卖共用入口）复用同一标题组件：图标、标题、信息入口在左，“换个市场”在右。标题桌面 20px、手机 18px，统一字重和间距，移除重复的大标题、口号与规则摘要。

普通市场使用纸黄底、墨绿标题、浅绿资料区和暖黄委托单；加密保留炭灰与金色；赌局使用深褐与金色。配色不影响红涨绿跌。手机标题会换行，按钮、选择器与返回入口继续采用游戏控件。

## 兼容与验证

旧档无小时记录时，根据原来的行情阶段推导当前时段；单纯查看不会改写存档。第一次选择日常活动或推进小时才记入新记录。新人生成年后从 07:00 开始。已有时钟、剧情与资金记录继续保留。

验证结果与运行命令记录在 `reports/v1.34/verification.json`。浏览器检查使用独立测试存档和 4174 预览端口，没有操作玩家 4173 页面或覆盖玩家档案。
