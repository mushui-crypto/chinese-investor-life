# v1.23 · 人物状态栏与导航

顶部左侧从游戏标题改为人物资料卡：头像、姓名、职业和家庭、年龄、游戏年份、回合，成年另显示本期第几天。点击资料卡可查看完整属性与账本。游戏标题仍在开场页，设置内可返回。

桌面左侧贴边固定显示七项属性和财务，包括现金、持有资产、欠款、净资产与家庭储备。每项属性的信息说明仍可打开，家庭储备不算玩家现金。侧栏独立滚动，切页时保留位置；交易室也能看到它。

生活、投资、资产、人情、小记、时代和案卷全部恢复直接入口，12–16 岁另显示集市。成长方向继续在故事下方折叠。手机不固定占用侧边空间，人物详情从头像或“属性与账本”进入；导航排成两行。

固定头部与侧栏的空间已计入页面布局。点击“去下单”和键盘切换交易输入时，让开顶部与底部遮挡。

没有修改游戏引擎、事件数据、存档格式或投资规则。新布局适用于已有存档，刷新即可使用。

- 检查股票、加密、赌局的下单定位、手机布局与生活费提示。
