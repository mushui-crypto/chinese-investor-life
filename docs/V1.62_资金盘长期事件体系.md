# v1.62.0 · 资金盘长期事件体系

在既有 Crypto 资金盘节点上扩展，继续使用同一个人生事件池、人生时钟、随机种子、账本、持仓及存档。原有学生旧事、弹珠、网赌与其他 Crypto 分支保留。

本版包含 35 个项目节点：扩写 11 个原有节点，新增 24 个节点。覆盖要求中的 22 个核心节点，并加入工资、奖金、首付、失业、伴侣、养老钱、家庭存款、亲友后果与多年重遇。使用长灯计划、晴禾协作、泊云工坊等虚构名称。

## 长期发生，而非连续章节

资金盘有独立的事件冷却和经历记录。同类事件之间至少间隔 90 天及两件其他人生事件；工作、家庭、日常消费、其他 Crypto 和网赌故事都可以构成这段生活。拒绝、退出与多年后的重新遇见使用更长冷却。不会通过预约强行指定下一资金盘事件。

首次接触、少量参与、真实回款、连续支付、追加、异常、恢复、再次异常、维护及消失各自有实际前因。不同虚构项目的本金、回款、异常及关系影响分别记录，旧项目的失败不算成新项目的历史。

旧的固定 24 岁介绍和 PON 连续事件不再进入新随机池；历史和已经打开的旧存档仍可读、可处理。旧介绍费选项改为免费说明情况，不再生成返佣或预约下一章节。新首次介绍本身会写入市场认知。

## 钱与页面数字

实际投入来自玩家明确选择。现金回款才增加现金；选择将收益留在项目内时，只形成项目余额，不能当作已经提现的钱。部分退出与取回本金均以实际持仓和费用计算，已离场的钱不会因后来项目消失再次扣除。

家庭参与须由玩家在明确标价的选项中同意，使用现有家庭储备，单独记录家庭本金、到账与损失，不混进玩家个人资产。父母养老钱、伴侣沟通、朋友参与和介绍人失联有各自的故事前因；介绍人不固定被写成骗子。

## 退出、复入与回看

初次到账、累计回款覆盖投入、第一次预警、恢复后以及后续异常均保留实际退出窗口。选择永久拒绝后，不再出现新入金与复入机会；旧持仓的退出、退款及追偿仍可处理。

人生小记与人生结局增加项目账页：第一次投入和到账、曾想退出的选择、异常与恢复、最高页面余额、累计真实提现、当前可提现及亲友影响。各类阶段后记与成就依照实际经历产生，不为了演出失败而清空账户。

现有 6 种退出后记、6 种失败后记、9 项经历成就。选择永久拒绝后，已有持仓的警号、退出、家庭后果和消失通知仍可处理；不再允许新增资金风险。

## 验收方式

运行 `npm test`、`npm run check:content`、`npm run qa:scheme-life` 和 `npm run build`。专项检查正常支付、未提现收益、延迟与恢复、退出、崩盘、家庭资金隔离、跨项目复入、永久拒绝、冷却、读档和重复结算。

开发项目中的报告存放于 `reports/v1.62.0`。发布包包含运行文件与本说明，不包含测试夹具或用户存档。

本次结果：960 项自动测试、19,453 项内容检查、35 项浏览器检查全部通过。覆盖 1,440、1,280 和 390 像素宽度，以及旧档锁定结果、跨项目首次回款、永久拒绝和家庭分账。

自然调度审计包含 32 个完整人生和 4 个家庭倾向样本；没有注入剧情队列或指定结果。32 个样本产生 359 次项目事件，实际观察到长期付款、恢复、退出和消失，89 次存读档核对无差异。家庭补充样本通过自然选择实际扣付家庭储备，个人现金及净值不变。为隔离节奏问题，模拟明确使用成年现金及健康下限；这不是整体游戏难度评估，也不代表每条分支每局都会出现。家庭储备未补写。逐节点专项另行验证未在这批自然样本抽中的分支。
