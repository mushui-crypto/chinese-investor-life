# v1.4 深夜赌局扩展

本版将旧红黑牌桌扩成七种实际可操作的赌局。斩龙按“押百家乐长连中断”制作，老虎机采用原创三轴奖表。牌、骰子、转轴与现金结算共用一份保存下来的结果，切换页面不会重抽。

## 发布范围

- 七种玩法及对应桌面：龙虎斗、百家乐、斩龙、骰宝、单零轮盘、午夜老虎机、红黑牌。
- 显示当前押注的返还倍数和金额；含本金、和局退注和零号规则写在相应操作旁。
- 观牌与路单、按局记账、大奖到账、全部现金开关，以及现金归零后的生活入口。
- 18 岁限制、市场操作次数、服刑限制、停止参与与既有调查/追缴机制。
- 旧版存档迁移；当前局面和随机状态随存档保留。

浏览器测试使用隔离存档，从真实按钮执行下注、观牌、切换、退出、读档和归零后找工作。大奖与长龙测试仅选择能自然产生相应结果的随机种子，没有替换结算结果。检查 1440、1024、768、390、320 像素布局、键盘操作与减少动态效果。

从 v1.0、v1.1、v1.2、v1.3 的真实发行压缩包加载旧代码，生成出生、成年及通关存档，再交给当前版本导入；另外用 v1.3 真实代码生成一局红黑牌及案卷，检查迁移保留原值。

验收结果与发行包校验记录在源码项目的 `reports/v1.4/`。具体玩法、奖表、现实资料与本作改编见 [赌局玩法与来源](V1.4_赌局玩法与来源.md)。

## 已知边界

这是浏览器离线人生游戏，不连接外部赌局。牌桌每局重新洗八副牌，轮盘采用单零版本，老虎机和红黑牌概率为本作参数。没有真人对局、充值、提现、自动追注或完整赌场全部边注。长期爽感与人生难度仍需更多玩家试玩来调整。

归零指现金归零，不自动清空其他资产。旧版没有保存的逐局明细无法补造；迁移会保留旧总账与最后一局，新统计从后续参与开始累计。
