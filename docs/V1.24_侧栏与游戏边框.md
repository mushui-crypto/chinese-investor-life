# v1.24 · 侧栏与游戏边框

童年右侧恢复生活安排与近况记录。先完成故事选择，再安排学习、休息或见朋友；三项操作统一在安排栏，主区域保留继续成长和集市。成年仍保留工作、日常入口和小目标。

左侧属性和账本贴住屏幕左边，高度随内容，不再铺满整屏。边框沿用游戏的深木色描边、纸张内框、圆角和底部实体阴影。窗口较矮时，侧栏限制最大高度并单独滚动，底部信息和边框仍可到达。

顶部头像、姓名和游戏日期，以及完整底部导航保持原样。窄屏仍通过头像和“属性与账本”查看详情，安排栏排到正文下方。投资交易室继续使用原有专属布局和生活入口。

本次修改仅涉及界面，没有调整游戏引擎、事件、存档格式或投资规则。

## 验证

两组浏览器检查共 158 项通过，无浏览器运行异常：人物布局 98 项、童年流程 60 项。使用独立测试存档，没有操作玩家当前的浏览器存档。

覆盖 1920、1440、1024、901、900、768、390、320 宽度和 600 高的短窗口；检查左侧内容高度、完整边框、固定位置、独立滚动和右侧近况展开。实测童年三项安排只出现一份、休息消耗一次安排，集市买卖和成年赠与正常，旧存档可快进。股票、加密和赌局在桌面及手机下单时，输入框不被固定头部与导航遮挡。
