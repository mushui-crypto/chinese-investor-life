# 历史事件与改编说明

本库是 24 个已核对的历史冲击、危机与市场机制事件，不声称每个都严格符合“黑天鹅”定义。事实栏来自链接资料；玩家身份、对白、个别投资结果、收益倍率、抽取权重与开放结局均为虚构。核对日期：2026-09-22。

真实回放按历史日期排序，仅对当时存在且玩家有资格参与的资产生效；时代乱流采用虚构模板并隐藏真实年份。日期只有年或月时，不补造日：年度/月度调度分别按该年/月的首个叙事窗口展示，并标注时间精度。玩家看到世界消息不代表可以即时交易所有海外市场。
