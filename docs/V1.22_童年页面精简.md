# v1.22 · 童年页面精简

6–16 岁时，先看故事，再做选择。移除顶部“处理故事”和右侧“先选完”的重复提示，保留结果页唯一的继续按钮。普通安排在可操作时直接显示在主区域。

- 成长方向收成一行，展开可修改、看三种专长或快进；修改处直接注明 18 岁后不能改。
- 人物栏默认显示头像、家庭与零花钱。七项属性、信息说明、账本与家庭储备均可展开，手机从“人物”进入。
- 6 岁导航为生活安排、人生小记、更多；12 岁加入二手集市；18 岁恢复七项导航。更多仍能进入市场查看开放条件，以及资产、人情、历史、案卷和成长设置。
- 故事未完成时点集市，会回到当前故事；不会跳过选择。进货、定价和收款继续按原来的真实游戏现金计算。
- 去掉泛泛的选项解释与童年结果套话；费用、门槛、无法选择的原因，以及结算后的金额和属性变化继续显示。
- 更多菜单向上展开，避免盖住自己的按钮；Esc 返回入口。切换页面和查看说明不执行游戏操作。

成年后的现金、剩余生活费、留足后的余额、求生提醒和工作入口保持原有规则。没有修改剧情结果、投资校验、成长收益、成年赠与或存档格式。
