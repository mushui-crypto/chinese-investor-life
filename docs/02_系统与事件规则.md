# 系统与事件规则

版本定位：可进入制作的叙事设计与数据契约。JSON 中的效果操作是待游戏引擎接入的声明，不是已完成的金融交易引擎。所有权重、收益档位、资产与贷款数字均为游戏初始参数，尚未平衡测试。

## 1. 状态

金额存整数“分”或十进制字符串，禁止用二进制浮点累计钱。档案包括：

- `age`、`turn`、`mode`、`birth_year`、`seed`、家庭和职业。
- `cash` 可用现金；`reserved_cash` 已冻结资金；`positions[]` 持仓；`claims[]` 未到账债权；`debts[]` 负债；`family_reserve` 家庭可提供的有限援助。
- `health` 体力健康、`stress` 压力、`skill` 谋生技能、`insight` 信息辨识、`trust` 关系信任、`fame` 名声、`credit` 信用，均 0–100。初始 70/20/10/10/50/0/60，家庭只覆盖指定项。
- `relationships[npc_id]`、`flags`、`history`、`pending[]`、`businesses[]`、`peak_net_worth`、`wipeouts`、`debt_free_turns`。
- `household` 记录父母在世、伴侣、子女、住房和照护责任；不能仅用一个“家庭值”替代所有人的意愿。

净资产＝现金＋冻结资金＋可计价持仓＋应收估值＋个人房产权益－负债本息。家庭房产不自动算玩家财产；截图估值不等于可变现净值。资产归零与现金断流分开判断：`investable_equity<=0` 才是投资归零，缺生活费但持有锁定股权是流动性危机。

## 2. 回合顺序

1. 应用上一回合预约的生活事件和已到期权益；并发按事件 ID 排序。
2. 支付基本生活费、照护费、债务利息与到期本金。现金不够登记欠款或逾期，不静默变负数，不自动贷款。
3. 读取时代状态及玩家当前已知信息，呈现主线或危机窗口。
4. 玩家选两项行动；大额投资、全职工作和创业扩张各占一项；单纯阅读、拒绝和求助不占资金。
5. 市场价格、持仓、手续费、资金费、到期及强平依次结算；然后做经营、工资和税费结算。
6. 用结算后状态生成个人事件候选，抽 1–2 张；已在本回合计算过损益的仓位不再套用剧情收益倍率。
7. 追加人物反馈与延迟队列；先危机处置，再开放结局判定，再推进年龄。

优先级：到期/强平 100 ＞ 生活断流 90 ＞ 已预约链 80 ＞ 年龄主线 70 ＞ 家庭关系 50 ＞ 市场/职业 40 ＞ 彩蛋 10。主线可延后一个回合，不能被危机永久挤掉。每回合最多 1 个世界冲击、2 个个人事件，超过预算的有效预约延至下一回合。

年龄主线是跨过目标年龄时注册一次的 `due_anchor`，不是要求玩家每次打开界面都刚好等于那个年龄。已注册主线延迟到下一回合时保留触发资格，不再被 `age_max` 淘汰；仍检查是否已经结算。普通预约事件继续执行实时年龄和状态检查。这样加速年份和危机插入都不会漏掉主线。

## 3. 钱从哪里来

家庭分三笔：童年零花钱、成年一次性赠与、仍由家庭拥有的储备。默认按开局家庭范围抽样，三者分别记账。赠与过一次就写标记，继承只有家人状态、财产权属及剧情满足时才发生。穷开局不凭空继承豪宅；富开局也有父母拒绝兜底的可能。

全职工作：基础工资×技能系数×地区成本系数，减生活费后才是可投入资金。副业与经营有投入、客户、成本、库存、欠薪和回款周期。破产后保底提供基础工作、零成本求职/求助与债务协商，不要求先付培训费才能活下去。

## 4. 各市场必须不同

| 类型 | 核心变量 | 必须出现的失败方式 | 不能怎样偷懒 |
|---|---|---|---|
| 股票 | 股数、价格、现金分红、交易限制 | 下跌、停牌、退市、连续无法卖出 | 跌停不能保证立刻止损 |
| 基金/债券 | 净值、利率、久期、申赎时间 | 回撤、赎回限制、违约 | 不把低波动写成保本 |
| 买入期权 | 权利金、行权价、到期时间、波动率 | 方向对但时间错、波动率回落、归零 | 买方损失不得超过已付权利金与费用 |
| 卖出期权 | 保证金、义务、对手方、交割 | 小赚多次后巨大赔付、追加保证金 | 不使用买方归零规则来封顶 |
| 期货/合约 | 方向、名义规模、保证金、费用、标记价格 | 强平、跳空、穿仓、平台中断 | 强平由保证金状态决定，不能只掷硬币 |
| 加密现货 | 数量、托管、流动性 | 盗损、锁仓、脱锚、平台违约 | 币价上涨不自动解除提现冻结 |
| 资金盘 | 实际转入、平台账面余额、真实提现、追偿 | 延期、限制提现、崩盘、追偿争议 | 账面“收益”不得自动当现金 |
| 天使/私募 | 出资、持股比例、融资稀释、清算顺序 | 长期锁定、倒闭、下轮缩水、退出落空 | 估值翻倍不得直接发工资般到账 |
| 房产 | 首付、贷款、评估价、租金、维修 | 空置、断供、出售慢、负权益 | 房价不能每回合必涨 |
| 做生意 | 订单、毛利、固定支出、现金周期 | 滞销、欠款、合伙争议 | 营业额不能等于利润 |

期权买方到期现金：看涨 `max(S-K,0)*数量*乘数`，看跌反向；净收益另减权利金和费用。剧情夸张的十倍、百倍指权利金回报，不是标的涨一百倍。卖方、实物交割、特定规则分别处理。

逐仓合约损失先从该仓保证金扣；全仓可侵蚀共享抵押资产；跳空穿仓只在已说明追索规则的产品中形成债务。借钱亏掉后贷款仍在。负油价原型仅作用于指定到期合约，不把所有原油、加油站和现货同时改成负数。

## 5. 借款与翻身

界面可保留玩家口吻“撸网贷”，机制记录为消费借款申请。没有真实平台入口、身份造假、骗贷或恶意逃债操作。

| 借款 | 条件 | 代价与限制 |
|---|---|---|
| 亲友 | 对方有储备且愿意、关系未断 | 有限额度、期限、信任；拒借也是事件 |
| 银行 | 稳定收入/经营记录或有效抵押、信用可接受 | 审批时间、用途、偿债比；非点按钮必批 |
| 消费网贷 | 成年、收入及信用条件、已有授信上限 | 利息、费用、到期、拒贷、累计负债限制 |
| 抵押 | 有产权、已有债权可核验 | 估价折扣、优先顺位、失去抵押物风险 |
| 展期/协商 | 已有债务、提供游戏内预算方案 | 对方可能拒绝；不得无理由清零本金 |

游戏初值建议：每月偿债额超过可支配收入 40% 下调审批，超过 70% 拒绝新增无抵押授信；这些是游戏参数。每笔债务记录本金、年化单利、费用、期限、已付、逾期和用途。利息按回合经过月份计算，复利仅在合同明确允许的模型中使用。申请费不能成为无限刷钱；贷款到账增加现金和等额本金，净资产不增加。

投资归零进入 REC 事件池，可在打工、经营、求助、出售资产、借款申请之间选；拒贷不得锁死进度。健康过低优先提供休息与求助；不将贫穷自动判定死亡。法律后果使用架空司法事件，不声称现实某地区能无条件“个人破产免债”。

## 6. 概率与信息

剧情分支的 `weight` 是**条件内设计权重**，不是现实胜率。`chance=weight/sum(eligible_weights)`。没有有效分支则配置错误，不能默默挑一个。随机种子在新周目固定，保存每次抽样结果；读取存档不重抽。

两种结算适配：
- **故事原型**：使用事件 `effect_profiles` 中预设结算档位，作为纯文字游戏的抽象事件。一个 `venture` 的投入在该事件内扣款、结算，不另触发市场引擎。
- **行情版本**：先让引擎按仓位算结果，再选符合结果的台词；禁用相同事件的抽象收益操作。历史冲击只改变对应风险敞口，绝不一刀切扣所有现金。

V1 JSON 配置为故事原型的数据，行情版本为后续接入规范。不要把同一笔钱同时交给两套结算器。技能可以开放尽调与更多信息、降低工作失败率，不会让黑天鹅消失；关系影响机会、援助和背叛动机，不直接改股票明日涨跌。

## 7. 抽取、互斥和组合

抽取先验条件（年龄/身份/时代/资产/标记）→ 排除已发生、冷却、冲突 → 计算权重 → 选择 → 锁定本次结果。预约事件再次检查条件；不满足的在有效期内等待，过期播放该链 fallback，不凭空补资产、职位、关系。

投资类候选权重随玩家主动选择对应领域上升；没开账户也可看到邀请卡，但入场选项受资金和资格限制。只有观察也可继续人生。18 岁以前不能真实开合约、申请贷款或参加天使投资。

同一回合共同市场冲击只抽一次，相关资产共享方向和流动性冲击；工资、店铺订单和房价可受同一衰退因子影响。不要给每个资产独立抛硬币制造“永远可套利”。

事件合成维度：家庭背景 × 人生阶段 × 主动职业/市场 × 财富与负债状态 × 时代 × 人际历史 × 选择 × 结果 × 延迟回响。只枚举符合因果的组合；数量不能直接相乘宣称全部可达。

## 8. 操作契约

完整效果模板在 `data/effect_profiles.json`，事件内含展开后的选择和结果。模板参数均指游戏金额。`stake_fraction` 以扣除冻结款与本回合必要生活费后的可投入现金计算，`min_cash` 只判定门槛，不是额外扣款；不足时隐藏该选项并显示原因。0 成本选项始终保留。

`venture`：扣 stake，并以选中结果的 `gross_multiple` 支付总返还；已扣投入不能再当亏损扣一次。`earn` 是税费后外部劳动收入。`spend` 不得超余额。`loan` 仅通过条件且抽到 approved 后创建现金/负债等额分录。`repay` 减现金同时减实际欠款，最多还现有债务。`illiquid` 将投入转为锁定权益，倍率只影响账面估值，`lock_turns` 结束后才允许退出；真实退出另受清算与流动性影响。`claim` 生成被冻结或待追偿债权，不发现金。`stat` 限幅 0–100。`flag` 幂等写入。`schedule` 创建有到期和过期规则的后续事件。

不存在的仓位、债务、家庭储备和资产不得结算；进入按钮就校验，结果应用时再校验。`repay` 前无债务则该选项禁用，不奖励“守信”。数据中 profile 的 prerequisites 是条件的一部分，不可忽略。

## 9. 结局

55 岁后可主动结算；80 岁触发本周目结算。按金钱、职业、关系、健康、遗产、历史伤痕分别生成一句话。主结局只是当前人生截面。先按 priority 选符合条件的最高项，同优先级由玩家选择视角；可同时拥有不同维度的后记。默认兜底“明天照常开门”。

继续同一角色、进入家庭下一代、平行命运重开都保留为后续选项；下一代只继承实际可转移资产、人际影响和未完成故事，不能凭空免除债务。病逝等终止只在单独生命模块实现后启用，V1 不用随机暴毙草率结算。
