# v1.32 股票界面与交易信箱

股票页换成木框证券看盘板：米黄底、深绿行情、暖色委托单。A 股、港股、美股的页签、股票选择和持仓更容易区分，所有价格、交易规则与 30 日走势保持原样。

交易室的“看行情 / 去下单 / 看持仓 / 生活”和时间推进移到内容区上方。滚动只影响正文，操作栏始终可用；加密与赌局保持自身配色。

最新一次成交或行情回执移入右上角交易信箱，有新回执时显示未读标记。点击查看金额和明细，阅读后清除标记；Esc 或点击外部可关闭。这里只保留最新回执，完整资金记录仍在资产账本。已读记录保存在浏览器会话中，不修改人生存档、现金和随机数。生活页原有回执继续显示。

支持电脑及手机窄屏；长信可在信箱内滚动，快捷下单继续将输入框定位到可见区域。未添加交易门槛、强制预留、复盘或行情卡。

验证记录见源码项目 reports/v1.32/QA验收报告.md。
