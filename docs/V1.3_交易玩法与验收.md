# 中国式赌狗 v1.3：专属市场与涨跌行情

更新日期：2026-09-22。本版把原来的通用投资窗口改为 11 个专属市场界面；股票加入大富翁式公司牌桌，加密加入币安风格交易室和真实历史片段。暴涨与爆仓都改变实际账本。

## 本版玩法

| 市场 | 界面与操作 |
|---|---|
| 股票 | 四家公司报价牌、消息、行情卡、100 股一手、逐笔 T+1、整手减仓、现金分红。 |
| 基金 | 三类配置、一次投入、定投与暂停；现金不足时跳过，不自动借款。 |
| 债券 | 票息和期限券面、信用研究、持有收息、到期兑付及违约风险。 |
| 期权买方 | 看涨/看跌、三档行权价、1/3/5 交易日到期、时间价值衰减与权利金损失上限。 |
| 期权卖方 | 独立义务席、保证金、回补、到期赔付与超保证金负债。 |
| 杠杆合约 | 股指、英镑、瑞郎、特定月份原油敞口，2/5/10 倍、双向交易与补保证金。 |
| 加密 | BTC、ETH、BNB、SOL、DOGE、ADA；现货 T+0、10/25/50/100 倍日内逐仓；独立虚构貔貅币骗局。 |
| 资金盘 | 群聊宣传、合同核对、投入、提现及失败追偿，账面余额与到账分开。 |
| 天使投资 | 三份项目资料、研究、参与、跟投、锁定与等待退出。 |
| 房产 | 房源、租金参数、全款/30% 首付按揭、装修与退出。 |
| 虚构网赌 | 独立牌桌、即时下注结算、累计输赢、停止参与、保留案卷。 |

每期三个压缩交易日，每日六次市场操作；三段行情后收盘，不推进年龄，不发重复工资。两次生活安排仍用于打工、学习、休息、借款等。可以直接推进人生，系统先结清短合约和历史片段，再处理生活收支。5 日期权的剩余日期自动完成。

股票每期一张利好卡与一张利空卡，每日最多出一张；下段行情叠加 ±6%，仍受当日 ±10% 的游戏边界。卡片不能绕过 T+1。不同日期买入的同一股票按批次检查，资产总览入口也执行同样限制。

加密采用深色底、黄色强调色和绿涨红跌，其他市场延续奶油白、青绿与木褐的游戏风格。桌面并排显示币种、图表和交易表单，手机改为单列与可横向切换的币种条。所有下单显示实际支付、剩余现金与生活预留，锁定时显示原因。

## 暴涨与黑天鹅都可游玩

离线抓取并校验 5 段 Binance 公共小时 K 线：2021 年 1 月山寨狂热、2021 年 2 月主流上涨、2020 年 3 月剧烈波动、2021 年 5 月急跌、2022 年 11 月平台危机，共 2,592 根。上涨会增加现货市值，也能强平做空仓位；下跌影响相反。区间高低价用于检查中途强平，避免爆仓后靠收盘反弹复活。

历史与虚构行情明确分开；不提前画未来，不给缺失币种补假数据，没有伪造订单簿。详见 [数据来源、数值和限制](V1.3_行情数据来源.md)。价格轨迹是真实归档，手续费、保证金及成交规则是游戏简化。

貔貅币不属于币安上市产品。它是不可卖出的虚构现货骗局，账面上涨不增加可兑现净资产；可以留证转追偿，受骗本身不触发犯罪记录。虚构网赌与既有法律叙事相连，个人参赌路线和明知组织推广的刑事路线保持区分，停止参与不能抹除旧记录。

## 运行与交付

`中国式赌狗-v1.3.zip` 为运行包，解压后 Mac 双击 `启动游戏.command`，或运行 `npm start`。需要 Node.js 22 或更新版，无需安装 npm 依赖；不能直接用 `file://` 打开。源码、下载脚本、测试与完整证据留在项目目录，旧的 v1.0–v1.2 压缩包保留。

存档仍为 v1 格式，读取旧档补充交易时钟，不重抽随机数，不重发资金。更换浏览器、电脑或端口前从游戏内导出备份。运行包 SHA256、ZIP 完整性、关键文件及启动器权限记录在 `reports/v1.3/release-manifest.json`。
