# v1.3 真实行情与改编范围

抓取时间：2026-09-22 UTC。运行时使用离线快照，不访问交易账户。

## 数据来源

使用 [Binance Public Data 官方说明](https://github.com/binance/binance-public-data) 中的 USD-M 合约月度小时 K 线归档。每个下载包对照官方 `.CHECKSUM` 文件校验 SHA256，再提取连续 96 根小时 K 线：24 根开场背景、72 根可游玩路径。

不是现货成交数据或标记价格数据，也不是逐笔订单簿。游戏现货与日内合约共享该历史价格比例，这是本作的简化，不能当作当年真实账户交易的复现。

| 标识 | 可游玩日期（UTC，含首尾日） | 币种 | 实际包含的行情 |
|---|---|---|---|
| doge2021 | 2021-01-28—01-30 | BTC、ETH、BNB、SOL、DOGE、ADA | 山寨币狂热与剧烈回撤；BTC 片段收盘较起点 +12.87%，DOGE +277.43%。 |
| rally2021 | 2021-02-08—02-10 | BTC、ETH、BNB、SOL、DOGE、ADA | 主流币拉升；BTC 片段收盘较起点 +15.45%，区间高点 +24.24%。各币并非同时上涨。 |
| march2020 | 2020-03-12—03-14 | BTC、ETH、BNB | BTC 片段收盘较起点 −34.91%，区间低点 −54.38%。缺失币种禁止下单。 |
| may2021 | 2021-05-19—05-21 | BTC、ETH、BNB、SOL、DOGE、ADA | 急跌与反弹；BTC 片段收盘较起点 −13.23%。 |
| nov2022 | 2022-11-08—11-10 | BTC、ETH、BNB、SOL、DOGE、ADA | 平台危机阶段；BTC 片段收盘较起点 −14.53%。 |

这里的起点为可游玩日期前一小时的收盘价。收益数字是对下载数据的计算，不是承诺玩家能获得的收益；买入时点、卖出时点、费用、方向与强平均会改变游戏结果。区间最高/最低价不等于能够成交的价格。

合计 5 个窗口、27 组币种与窗口组合、2,592 根小时 K 线。每根保存 `openTimeMs, open, high, low, close, volume`；价格与成交量保留原始 CSV 十进制字符串，使用时才转换为显示或游戏指数。原始下载包与官方校验结果在源码项目 `reports/v1.3/market-data/` 与 `crypto-fetch.txt`，快照内逐组保留原始来源 URL 和 SHA256。

## 游戏中的使用方式

- 首日开盘且没有加密持仓时选择一次片段；保存后不能反复重选回拨。种子抽选的候选同时包含上涨与下跌。
- 最初只显示过去 24 小时。每次推进行情增加 8 小时，最多 9 次；界面不会提前画出未来 K 线。
- 真实价格转换为基准 1,000,000 的游戏指数。下单扣人民币游戏资金，盈亏按价格比例计算，不声称复原历史人民币汇率。
- 现货收益按已观察收盘价更新；高杠杆合约同时检查该段小时最高/最低价是否越过维持线。由于没有逐笔路径，强平采用保守简化，可能将该仓本金归零；不会事后因价格反弹复活仓位。
- 逐仓合约杠杆 10/25/50/100 倍，维持保证金为名义本金的 0.5%，每段费用为名义本金的 0.02%，当日收盘结清。这些全是游戏参数，不是对应币种当年的交易所费率或保证金阶梯。
- 进入人生结算时，未走完的片段与短合约先自动走完；已经按真实片段定价的现货不会再叠加同一期虚构半年涨跌。下一期默认恢复种子行情，界面明确标注。
- 不存在历史数据的币种显示缺失并禁止下单；不拿虚构曲线冒充历史。貔貅币属于独立虚构骗局，无正规合约，不在这些真实归档内。

本交易室只参考币安常见的币种列表、K 线、交易表单和持仓布局。没有实时行情连接、真实委托撮合、历史深度、限价排队、真实资金费率、标记价格或实盘账户。

## 重新生成

在源码目录运行 `npm run data:crypto`。需要 Python 3、curl 和网络，不需要 API 密钥。脚本下载归档、检查 SHA256、时间连续性与 OHLC 边界后，同时生成 `data/crypto-history.json` 和 `src/game/crypto-history-data.js`。游戏运行不依赖这个下载步骤。
