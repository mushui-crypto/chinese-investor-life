# v1.25 · 人物场景定位修复

人物和对白原本在正文里排在剧情、成长设置后面，而房间背景已经固定铺满全屏，两者位置互不对应。现在移除正文场景占位，将人物和对白放到独立的固定前景层。

半身立绘从画面下沿出现，身体自然延伸到屏幕外，不再悬在椅背上。对白靠近人物。展开设置、改变剧情长度和页面滚动时，人物不会跟着正文移动。装饰层位于操作卡片和导航下方，不接收点击。

手机、平板窄屏和较矮的窗口收起装饰人物及对白，继续显示顶部头像。没有新增空白区域，也没有移除故事选择、生活安排、重要演出和上一期账本。人物与背景继续随年龄、健康、财富和服刑状态变化；出生开场和交易室保持原样。

本次只调整界面，没有修改引擎、剧情数据、存档格式和资金规则。

## 验证

人物布局 121 项、童年流程 60 项浏览器检查通过，共 181 项，无浏览器运行异常。测试使用独立存档，没有操作玩家当前存档。

覆盖 1920 至 320px 宽度、600px 高短窗口、童年到成年、富裕、低谷和服刑场景，以及股票、加密和赌局交易室。确认正文不再包含人物占位，装饰不拦截选择按钮，窄屏收起前景，上一期账本仍能展开。另在 1440×760 窗口展开成长设置并实际滚动 160px，人物坐标保持一致。
