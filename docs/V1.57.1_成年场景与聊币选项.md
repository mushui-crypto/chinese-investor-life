# v1.57.1 成年场景与聊币选项

“初入成年”阶段页尚未选择生活重心时，过去会回退到隐藏的当天作息，因此大学生看到了家里吃早餐的插图。现在默认按身份显示：学生用大学课堂，在职用工作场景，待业用找工作，自营用照看生意，退休用户外生活。已选重心继续匹配对应场景，眼前的随机事件仍优先显示自身场景。

场景选择只影响展示，不自动选择生活重心、不改变时钟、精力、随机数或存档；“展开今天”仍按实际作息显示。

此前只修改了未升学分支“朋友晒出炒币收益”，漏掉大学分支“宿舍里第一次聊币”。现补齐三个选项：

1. 问室友投了多少、赚的钱提出来没有。
2. 查查加密货币怎么买卖、怎么亏钱。
3. 和家里商量试水预算。

结果文字同步说明提问、查规则、沟通预算后的反馈。事件及选项 ID、属性加成、市场认知标记均保持原值；选择不会自动买币或转钱。生成脚本同步覆盖两个分支，旧存档按现有 ID 读取新文字。
