# v1.45 出生场景修复

原开场把独立婴儿摇篮叠在空房间上，造成婴儿像被单独放在过道里的观感。现改为家人和新生儿直接画入场景，移除独立摇篮及其姓名贴牌；顶部人物卡继续保留婴儿头像。

## 配图

使用内置 imagegen，以原来的病房、家中卧室和单人房为参考重新绘制。保留原画风、色彩与 v1 原图，新增 5 张 1536×1024 原图及对应 WebP：

| 场景 | 适用家庭 | 游戏资源 |
| --- | --- | --- |
| 父母与护士照看孩子 | 普通医院出生的家庭 | `public/assets/birth-hospital-v2.webp` |
| 父母在家中照看孩子 | 乡镇务农、小店家庭 | `public/assets/birth-home-v2.webp` |
| 父母在单人病房抱着孩子 | 宽裕家庭、商人家庭 | `public/assets/birth-suite-v2.webp` |
| 妈妈夜里抱着孩子 | 单亲抚养家庭 | `public/assets/birth-mother-v2.webp` |
| 外婆在床边抱着孩子 | 隔代照护家庭 | `public/assets/birth-grandmother-v2.webp` |

同名 `.png` 为生成原图。完整生成提示词、参考输出来源与项目路径记录在源码目录的 `reports/v1.45/birth-scenes/generation.json`。

提示词的共同约束：人物和婴儿集中于左半幅，右侧留出剧情区；减少空地；保持统一透视与人体比例；婴儿头部得到支撑；不添加多余肢体、第二个婴儿、文字或 UI。单亲和隔代家庭分别只出现妈妈或外婆。

## 布局与验证

桌面保持场景铺满背景，右侧剧情避开主要人物。900 像素以下，插画与正文改为上下排列；插画聚焦家人面部及宝宝，正文和选项不会盖在人物上。

出生故事、属性、资金与随机数规则未修改。已有出生存档直接使用新图，不需要重开。

- 出生规则测试 6 项通过。

- 已检查医院、单亲、外婆场景和窄屏实际截图；使用独立 4174 端口，没有操作玩家 4173 存档。

实际截图与检查结果位于 `reports/v1.45/birth-scenes/`。
