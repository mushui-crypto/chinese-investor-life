# 成长阶段、零花钱与大学兼职

## 当前规则

- 童年节点：出生 0 岁 → 幼儿园 3 岁 → 小学 6 岁 → 初中 12 岁 → 高中 15 岁 → 成年 18 岁。
- 每阶段 2 点精力；习惯使用原有学习、休息、社交动作，以该阶段剩余年数结算成长。推进阶段不代选活动，未用精力不结转。显式快进按偏好自动安排。
- 旧档位于 1、5、11、17 等年龄时，接着走到下一节点；不回退年龄，不重算历史属性、现金和故事。旧事件 ID 保留。
- 6 岁前不发零花钱。6–17 岁每月 ¥200，个人花销范围：小学 ¥120–180、初中 ¥150–190、高中 ¥170–200。家庭另负担学费及吃住。
- 每个符合条件的月只结算一次，支出使用存档内确定性随机数。新人生总计 144 个月零花钱，到账、支出分记流水，余额才计入现金。阶段入口结算首月，阶段推进汇总其余月份。
- 旧学龄档不补发或追扣过去的月份。成年赠与仍按原家庭开局生成、仅发一次，与零花钱分账。
- 四年制本科：18 岁入学，22 岁毕业。18–21 岁在读只可兼职，不允许直接求职、日常投简历、剧情正式入职或熟人介绍固定岗位。未升学者 18 岁起可正式求职。
- 兼职：09:30 / 13:00 半天班、18:30 晚班。占用课堂时间损失学业，工钱完工即付；不获得固定月薪，仍受每日接活上限、疲劳和现金流水约束。
- 已有大学生旧档的提前正式岗位停止未来计薪，现金与历史流水保留；尚未完成的正式入职取消，有材料费的短训退回材料费，试工工钱照付。

## 界面

- 活动次数统一为精力，市场操作仍单独计数。
- 阶段习惯与“上小学 / 上初中 / 上高中 / 步入成年”分行，升学按钮在右下角。
- 在读的正式求职入口替换为“兼职与日程”，作息状态显示 22 岁毕业，规则文案按在读/在职分别展示。
- 移除正文 60–100ch 的固定宽度上限和强制平衡换行，正文使用所在面板宽度自然换行；保留对话气泡、侧栏等组件本身的布局宽度。
