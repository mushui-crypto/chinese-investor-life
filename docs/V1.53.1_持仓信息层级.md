# v1.53.1 持仓信息层级

本轮集中调整加密交易室的布局与阅读顺序。

- 持仓常驻上方：币种、当前市值或权益、浮动盈亏、成本或保证金、操作依次排列。盈亏突出，成本弱化。
- 单笔持仓不再重复显示合计，多笔时才显示总市值与总盈亏。
- 卖出或平仓操作靠右，追加保证金折叠展示。
- 成交记录和行情动态放在下方切换；仅刷新记录区域，保留持仓滚动位置及正在填写的交易内容。
- 行情按日期分组，时间单列，减少重复日期和逐条分割线。
- 旧存档没有结构化字段时使用“时间 / 成交摘要”，不展示空金融字段。
- 工作区小于 760px 时，持仓按币种和市值、盈亏和成本、操作三行排列。没有固定空白占高，长列表区内滚动。

本轮未改动交易计算、费用、资金或存档规则。

验证：成交与存档兼容测试 6/6 通过，源文件语法检查及静态构建通过。浏览器访问受到工具安全策略限制，未完成实际窗口尺寸的视觉验收。
