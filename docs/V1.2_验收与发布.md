# 中国式赌狗 v1.2 验收与发布

验收日期：2026-09-22。此版本将成年阶段的主循环移到投资市场，增加逐步开放的投资资格，并完成全局可读性、人物演出与连续关系剧情的整理。

## 现在如何玩

处理关键故事后，成年玩家默认回到投资计划：看现金与旧仓，选择建仓、退出、复盘或观望，再推进时间结算。工作、生意和借款仍可作为积累本金或归零后的出路。每回合两次安排可以不用完，不强迫投资。

普通成年回合每两回合最多补入一件随机故事，并优先考虑市场相关经历；主线、危机、调查、到期旧约和历史冲击保留自己的触发规则。童年与服刑保留各自的生活节奏。

固定种子 `market-first-life` 完整走到 80 岁：80 个成年回合提供 160 次可选安排机会，期间经历 58 次成年故事，160 ÷ (160 + 58) = **73.4%**。12 个主线章节和三位熟人的初见全部经历。

这个比例只衡量可安排机会相对于故事打断的设计容量。安排可以用于工作、休息等其他行动，因此它不能当作实际交易次数、玩家在市场的停留时长或所有路线的固定比例。约七成是本版的节奏目标，后续可通过实际试玩继续校准。

## 启动与交付

源码项目路径：`/Users/moss/Desktop/中国式赌狗`。

运行发布包：`中国式赌狗-v1.2.zip`。解压后在 Mac 双击 `启动游戏.command`，或运行 `npm start` 并访问 `http://127.0.0.1:4173`。需要 Node.js 22 或更新版本，无需安装 npm 依赖。不要直接双击 `index.html`。

源码目录保留测试、开发脚本、验收截图与原始美术；运行包包含静态游戏、内容数据、压缩美术、启动器和说明。旧版 v1.0 / v1.1 压缩包保留，未覆写。包完整性与文件哈希记录在源码项目的 `reports/v1.2/release-manifest.json`。

存档按浏览器与站点地址隔离，换设备、浏览器或端口前应先从游戏内导出。真实旧版存档迁移已验证，已有现金、持仓、债务、预定剧情结果和随机状态保持不变；新增市场经历仅从已持有产品和可确认的实际记录恢复。

本轮检查覆盖功能与指定浏览器、尺寸和路线。长期难度平衡、所有随机组合的人工试玩及其他浏览器兼容性没有据此宣称全部完成；七成市场体验仍应以实际试玩感受检验。
