# v1.20 游戏表单控件

下拉菜单、文字框、金额框和多行输入统一使用游戏样式。普通界面沿用纸张、木框、青绿与金色；加密交易室使用深色边框和金色选中状态。复选框、单选项与已有开关保持一致。

数字框去掉系统小箭头，换成可点击的加减按钮。加减仍遵守原字段的单位、最小值和最大值，直接输入、复制粘贴与小数金额照常可用。必填或超出范围时在字段旁显示提醒。

下拉菜单使用独立浮层，能显示在弹窗和滚动容器上方。方向键选择、Home / End 跳到两端、Enter 确认；Esc 只关闭菜单，Tab 转到下一项。禁用选项不能选，读屏名称包含当前选择。320 像素宽度也保留至少 44 像素的选项点击高度。

覆盖开局设置、家庭与存档选择、童年方向与集市、所有交易室、借款、开店、还款、投入限额和试玩记录。原有字段仍负责保存和提交，没有改动投资、借贷、生活费或剧情引擎。

检查包括实际开局、期权方向与到期日、两位小数下单、100 倍合约、借款到账、反馈保存、键盘和窄屏。报告在源码项目的 `reports/v1.20/`，自动化使用独立浏览器环境，未修改玩家存档。
