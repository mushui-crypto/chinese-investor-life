# v1.41 成长故事线与交易自律

本版把出生到成年改成连续的人生线。出生故事结束后从 1 岁开始，1–16 岁每年随机抽取一件该年龄专属事件；每岁有两张候选卡，选择会改变学业、自律、健康、压力、本事、眼力或人缘。快进到成年仍逐年结算，不会静默跳过事件。

## 固定教育时间线

| 年龄 | 阶段 | 关键规则 |
|---|---|---|
| 0–2 | 学龄前 | 出生故事后逐年成长 |
| 3–5 | 幼儿园 | 每年一件年龄专属事件 |
| 6–11 | 小学 | 学习与生活选择开始稳定积累属性 |
| 12–14 | 初中 | 12 岁起可选玩二手集市 |
| 15–17 | 高中 | 16 岁通过父母谈论股票完成认知 |
| 18–21 | 大学或社会起步 | 18 岁根据真实属性决定升学路线 |
| 22 起 | 毕业后或成年生活 | 大学路线在 22 岁记录毕业 |

升学分数以学业为主，并结合自律、本事、眼力、健康与压力；当前录取线为 38。没有考上大学不会触发失败，而是进入社会路线。两条路线都能继续获得工作、关系与市场故事。

## 风险经历的年龄顺序

- 16 岁：从父母的真实盈亏与开户讨论中认识股票；18 岁才开放证券交易。
- 18 岁：大学路线由室友介绍加密货币；未升学路线由工作或社会关系介绍。
- 20 岁：大学路线由同学或室友带来网赌链接；未升学路线由社会关系带来。
- 24 岁：熟人推介高息项目后，才开放资金盘剧情入口。

这些事件只建立认知或接触，不自动下单、下注或扣钱。玩家仍需主动选择，市场自身的现金、行动次数、经验、授信和服刑限制继续生效。

## 学业与自律

新增两项独立属性：

- 学业：记录童年到高中的学习基础，主要决定 18 岁升学。
- 自律：参与升学，也延续到交易行为。有效自律会被压力与上头暂时压低。

学习、订正、坚持计划会提升学业或自律。亏损前主动退出会记录严格止损并改善自律；在亏损杠杆仓上追加保证金会降低自律、提高压力和上头；低有效自律下的大比例投入会记录冲动梭哈，扛单到强平会留下对应经历。自律提供反馈与后果，不替玩家禁止下单或自动平仓。

## 兼容与验收

- 旧存档载入时补齐学业、自律与教育记录，不改现金、持仓、债务或随机序列。
- 已跨过相应年龄的旧档会补记认知入口，避免旧人生被新版剧情永久锁住。
- 内容校验：12,179 项通过；共 256 个事件、770 个选择、1,099 个结果。
- 自动测试：411 项通过，覆盖逐年成长、升学分流、16 / 18 / 20 / 24 岁解锁、自律反馈、存档迁移和完整 0–80 岁人生。
