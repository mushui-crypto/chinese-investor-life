# v1.47 期货与外汇

原“杠杆合约”更名为“期货与外汇”。“杠杆”保留为下单参数，入口名称直接说明这里能交易什么。

| 分类 | 三个标的 |
| --- | --- |
| 金属 | 黄金、白银、铜 |
| 能源 | 原油、天然气、汽油 |
| 农产品 | 大豆、原糖、棉花 |
| 指数 | 游戏 A 股指数、港股指数、美股指数 |
| 外汇 | 美元 / 人民币、欧元 / 人民币、欧元 / 美元 |

分类切换后展示该组三个品种。所有品种均为游戏中的保证金交易，沿用 2 / 5 / 10 倍逐仓，支持做多、做空、平仓一半、全部平仓和追加保证金。

## 怎么玩

选择类别和品种，输入人民币保证金，再选方向与杠杆。开仓前可查看上下波动 1% / 3% 的盈亏估算和强平距离。追加保证金只增加安全余量，不增加名义仓位；每段行情按名义仓位收 0.02% 持仓费用，主动平仓扣 0.2% 手续费。逐仓损失限于该笔保证金，贷款仍需偿还。

金属、能源和农产品使用开局 100 点的游戏行情，各品种波动不同。指数合约直接跟随游戏股票页的三地大盘；A 股指数仅在 09:30–11:30、13:00–15:00 开平仓。

外汇采用用户选择的汇率多空玩法，保证金和盈亏都用人民币，不实际生成美元或欧元余额。页面直接写“1 美元 = 7.2000 人民币”这类报价。以美元 / 人民币为例，做多美元在美元相对人民币升值时盈利，做空美元方向相反。欧元 / 美元同理，做多的是欧元。

## 行情与存档

- 三个指数与股票页使用相同的实际日线和开场模拟历史。
- 美元 / 人民币、欧元 / 人民币生成两组基础汇率，欧元 / 美元由它们相除得到；实时价、跨期结算和模拟历史保持一致。
- 新增行情不额外消耗人生事件的随机数，不因增加标的而改写原有随机事件路径。
- 旧版英镑、瑞郎、综合股指和异常原油不再作为新交易选项，原持仓仍可读档、结算、补保证金和平仓。
- 开放条件仍为成年、自有金融资产 50 万、眼力 40；没有参与经验或练习门槛。

## 验证

531 项自动化测试通过。新增验证包含 15 个品种的 90 组方向与杠杆组合、三地指数同步、交叉汇率、A 股指数交易时段、跨期共同报价、天然气强平、外汇补保证金和旧持仓退出。

独立测试页面实际完成美元 / 人民币做空开仓、部分平仓和全部平仓；五个分类在桌面和 390px 手机宽度下均可切换，没有页面横向溢出或控制台错误。报告位于 reports/v1.47/。
