# v1.49 生活费安排

- 顶部突出今天的缺口，分别列日常开销、预计日收入与手头现金；不把整期生活费当成今天的缺口。今日已够、仍处应急期时，标题显示“生活费安排”。
- 降低开支、打工或课余兼职、出售资产、熟人工作机会分成紧凑的四行，说明与按钮一一对应。
- 借款默认折叠；每项显示利率、期限、可申请上限或不可用原因。信用卡套现和高利贷归到高成本借款，明确到账扣费。
- 调整开支、兼职日程、借款表单有返回生活费安排入口；资产和工作机会页面保留返回入口。调整开支、接零工等操作后仍有缺口，重新显示更新后的安排。
- 精力不足时保留查看入口，实际操作遵守原条件。学生在熟人工作机会为空时引导到兼职日程。
- 沿用纸色、墨绿标题、统一行间距和分隔线；窄屏改为上下排列，长内容只在弹窗内滚动。

## 验证

在独立 4174 端口导入测试存档，核对：开支调整后缺口从 150 元变为 112.5 元；兼职、资产、工作机会和借款的往返；借入 500 元后显示今日已够；零精力及无可变现资产状态。检查桌面、1280×600 矮屏、390×667 手机布局。截图保存在 reports/v1.49。
