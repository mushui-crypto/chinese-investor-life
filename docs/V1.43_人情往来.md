# v1.43 人情往来

人物不再作为全量图鉴展示。开局只有家人，故事和实际行动中出现过的人才会进入人情往来。

## 怎么玩

1. 故事里遇见人物，或在求职、接活、学习时结识同事与师傅。
2. 在对应人物下见面、赴约，查看最近往来和个人信任。
3. 信任或本事达到条件后，接受介绍的工作或订单；交付倒计时留在该人物下面。

拜访每人每天一次，用 1 次生活安排，个人信任 +4、人缘 +2、压力 −3。按约见面时个人信任改为 +8，超过约定期限未见面 −12。有约定的人排在前面。界面直接显示成本、收益、期限和无法操作的原因。

老周信任达到 55，可以介绍月薪 2,800 元的岗位，两天后入职。赵姨和吴师傅的机会沿用原有工钱、技能、材料费与交付规则，没有增加工资或重复领钱入口。未认识介绍人时，其他入口和行动校验也会阻止接单。

林夏的关系发展放在她的条目中：20 岁、个人信任达到 60 可以结伴，每月共同生活开销 +900 元；22 岁且已有伴侣可养育孩子，每月照护开销 +2,000 元。修复关系的显示和结算使用同一个信任值，单次 +10。小满出生或在故事中出现后才展示。55 岁后的交接与封盘集中放在页尾。

陈经理、金老师、杜衡和沈岚保留实际故事记录，后续通过故事继续往来，不显示无效的拜访按钮。已离世的家人保留记录并停止拜访。整理交接清单不会凭空认识一个师傅。

## 出场与存档

- 新存档记录 `peopleMet`。剧情激活即登记画面上出现的人；选定结果只补充实际发生的相遇，不扫描其他结果或未来剧情。
- 求职、接活和学习的结果明确写出新认识的老周、赵姨或吴师傅，随后出现在人物页。
- 旧存档根据已发生故事、当前故事、已有往来、拜访、约定和家庭关系恢复。不会从待选候选、排队事件或未触发支线提前加入联系人。
- 不重算历史现金，不重抽随机数，不补发工作收入。
