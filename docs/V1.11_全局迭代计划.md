# v1.11 全局体验目标与验收

授权：全部完成此前提出的七项全局改进；需要实质取舍时再询问。保持现有场景风格、成年投资为主要玩法、隐藏走势与剧情答案。旧存档与旧运行包继续保留。

## 必须完成

1. 统一“继续”主操作：显示实际推进幅度，盘中、换日、跨期使用同一入口；还款、短期到期、求生和重大待选故事处停下。批量推进有边界、不会漏结或重复结账。
2. 跨系统因果：暴富后消费承诺、回撤、债务披露、工作与关系形成可持续的事件链，有实际账本和状态后果。
3. 分化重建：依据技能、关系、信用、失业和出狱经历提供可执行机会，明确时间与现金代价、机会可耗尽、不凭空抹债。
4. 中后期目标：清偿亲友、稳定经营、安居、退休准备与传承等目标由现有资产、关系和行为验证；不强制婚育，不发凭空奖励。
5. 人物记忆：具体人物记录帮助、失约、陪伴与分歧；处境变化带来不同对话、请求和后续，支持修复，不能重复领取援助。
6. 人生账单：依据真实流水与选择生成高光、低谷、债务成本、关系状态和关键决定，加入结局与可导出小记；旧存档缺失的信息明确留空。
7. 重玩差异：种子与家庭影响人物和机会次序，存在不同动机与结果；仅已遇到内容进图鉴，不提前暴露隐藏分支。
8. 节奏验证：保守工作、激进交易、归零重建三条路线实际操作，分开记录交易、剧情、生活/账单、导航时间与动作。约七成投资是成年一般阶段的目标，不强迫危机和服刑阶段交易。报告自动化计时的局限，不把它当真人留存测试。

## 交付证据

- 新机制的确定性、存读档、重复提交、钱账与年龄校验测试。
- 出生至晚年、提前结局与继续、求生失败/重建、入狱与出狱路径回归。
- 桌面及 320/390/768/1440 宽度的实际点击和键盘检查；玩法指引可达，无透露未来的字段。
- 从真实旧版本包生成存档并迁移；原有流水、已锁定事件、随机状态及旧持仓保留。
- 本地源码、构建与新压缩包一致。完成前按以上八项逐条审计，未完成项不能用旧测试替代。
