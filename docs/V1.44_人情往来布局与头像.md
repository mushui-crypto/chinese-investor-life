# v1.44 人情往来布局与头像

## 布局

- 桌面左侧为联系人，右侧只显示当前人物详情。同一木框纸面内使用深浅麦色和完整分界线，减少长列表和重复窗框。
- 人物头像、身份、姓名、个人信任置于详情顶部。日常来往、工作机会、关系与家庭分节排列，按钮与对应收益、费用和条件靠在一起。
- 待赴约、工作机会可分别筛选，待赴约人物优先。已离世家人保留记录，未出场人物继续隐藏。
- 手机上使用横向头像列表，进入页面直接定位到人物区。按钮不小于 44px，选中状态除颜色外还有边线，键盘可选人和切换筛选。

## 操作路径

- “人物与约定”直接进入人物页，有约定时自动筛选待赴约者。
- “接单赚钱”直接进入工作机会，不再另开接单弹窗。
- 拜访、赴约、接单、确认关系后留在当前人物，显示结果和实际信任、生活安排次数、现金变化，不再弹出“继续”确认框。
- 接下的工作显示交付倒计时；交付与取消记录进入该人物的往来记录。已接过的旧机会不继续占据操作区。
- 空筛选提供返回全部人物的按钮，工作机会为空时可去找工作。历史记录折叠，并去除同一故事重复生成的记忆条目。

## 头像

使用内置 `image_gen` 工具分别生成 14 张暖色水彩头像，覆盖 12 个人物。其中家人提供普通家庭、单亲抚养、隔代照护三个版本。头像是人物识别插图，不改变人物出场或家庭状态。

- 游戏资源：`public/assets/people/*.webp`，256 × 256，共约 186 KB。
- 完整生成图：`docs/art/people-v1.44/*.png`。
- 完整提示词：[people-portraits-v1.44.json](art/people-portraits-v1.44.json)。
- 来源对应表：[people-portraits-sources-v1.44.json](art/people-portraits-sources-v1.44.json)。

统一提示方向为暖棕铅笔轮廓、水彩与纸张纹理、自然暖光、居中的头肩构图；按人物分别设定发型、表情、眼镜和衣着。生成图经等比缩小和 WebP 编码用于游戏，没有重新绘制或改变五官。
