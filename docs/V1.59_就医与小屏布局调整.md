# 就医与小屏布局调整

住院须先付足 ¥1,500 现金，不能用当天尚未到账的工资、持仓市值或新增医疗欠款垫付。支付成功后才推进住院日，恢复至 60 健康。医疗现金支出进入日常消费账单，旧档已有债务保留。当天供餐、不计工作工资，房租等固定费用仍照常处理。

健康告急时暂停快速推进，仍可查看就医费用、筹钱或选择“暂不治疗 · 过一天”。后者不收住院费、不获得治疗恢复；缺食按原有规则扣健康，降到零进入结局。没有把现金不足直接当作死亡条件，也没有新增无依据的每日疾病扣血。

“展开今天”与“按安排快进”相邻，前者为主按钮，后者为次要文字按钮。“去投资市场”独立放在另一侧。健康提示与结算提示去掉重复边线，保留操作区的一条分隔线。

12–17 岁的学生日常故事及原有少年金钱故事，其选择页与结果页统一放入底部文字操作区。保留所有选择、真实结果及读档状态；主要人生事件仍有配图。

二手集市的商品和数量字段顶部对齐。数量预置按钮不会再把左边的下拉框推向中间。按容器宽度切换单双列，窄屏付款按钮铺满，空错误提示不占间距，保持 44 像素以上的操作目标。

验证：768 项单元测试通过；就医浏览器检查 19 项、学生故事浏览器检查 172 项通过。浏览器使用隔离的 4174 端口与测试存档，不修改玩家存档。小屏布局报告另见 reports/v1.59/child-market-layout。
