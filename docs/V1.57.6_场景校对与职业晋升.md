# v1.57.6 场景校对与职业晋升

## 身份与剧情

- 修复大学在读仍显示“离职待业”。旧档读取时恢复大学生身份，保留现金、账本与既有回单。
- 删除 123 处与离职无关的 `employed=false` 效果；保留有明确辞职、裁员情节的效果。失败的工作申请、学习、家庭聊天和投资结算不再清掉现有工作。
- 未买房的大学生只接触居住成本的介绍；业主交付问题要求实际持有房产。旧档里已经排入的住房事件改为了解房源、计算租房预算或继续生活，全部免费。已支付过的旧回单仍按实际记录展示，不追溯补发。

## 职业路线

| 路线 | 岗位顺序 | 每次晋升的月薪增量 |
| --- | --- | --- |
| 门店服务 | 门店店员 → 资深店员 → 门店副店长 → 门店店长 | +500 / +900 / +1400 元 |
| 仓配物流 | 仓配助理 → 仓配专员 → 仓配组长 → 仓配主管 | +500 / +1000 / +1500 元 |
| 文职运营 | 运营助理 → 运营专员 → 运营组长 → 运营主管 | +600 / +1100 / +1700 元 |
| 技术维护 | 技术学徒 → 维护技术员 → 资深技术员 → 技术组长 | +700 / +1300 / +1900 元 |

职业分配由存档种子、求职来源、教育和技能、已经历的人物故事共同决定；熟人介绍与学徒机会指向相应路线。保存后不重新抽取，不消耗市场的随机序列。以上都是游戏数值。

每一级分别要求本岗位有效出勤 90 / 180 / 360 天，另有对应的谋生本事和自律要求。请假、旷工不计有效出勤；迟到、工作出错、疲劳达到 65 或健康低于 35 时暂缓评定。同一天不重复晋升，每次仅升一级。新工资从次日计薪，每月 10 号照常发上月工资，晋升消息不会直接增加现金。

在“工作、晋升与生活规则”查看当前岗位、下一岗位、工资增量与缺少的条件。离职后重新入职会重新开始岗位成长。已有工作的旧档会在后续操作时确定具体路线，保留原工资、在岗记录与已赚收入，不追溯发放晋升奖励。

## 场景

- 新增 50 张 WebP：32 张大学宿舍场景（16 类各两张）、8 张职业场景（4 类各两张）、10 张家庭、预算、金融资料、夜班及空房间等补充图。
- 学生的居家读书、吃饭、电话、交易、睡前、睡眠、起床场景改为上床下桌的大学宿舍；课堂、餐馆、兼职等活动保留其实际地点。
- 盈利、亏损、提现暂停分别选择对应图；学习不再使用亏损曲线。所有场景插图框统一 3:1（按用户确认恢复），窄屏也保持该比例；上铺睡眠与起床按人物位置裁切。
- 宿舍与职业同类配图随日期稳定轮换，单纯重绘界面不会换图或改变游戏随机结果。
- 职业背景采用无人工作环境，由游戏按实际年龄显示角色，避免所有岗位和年龄共用年轻白领。
- 全部 272 个事件文案参与映射检查；重新检查 87 项已注册图与常用背景、补查 N10 人物图，并逐张检查本次 50 张新图。未宣称检查所有未使用的旧源图。
