# v1.53 交易布局与疲劳反馈

- 加密说明区不再贴边，与标题、模式按钮和交易主体共用边距；规则展开后换行，不遮挡或挤压下单区。
- 按中央实际可用宽度调整：宽屏三列，中间宽度将下单区放到下一行，窄屏单列。
- 成年后在健康旁显示疲劳数值和进度条。50 起提醒注意休息，达到 65 时显示“疲劳导致工作出错，工作收入减少 25%”。
- 工作、半天兼职和晚班兼职在操作前展示折后收入及原因，收款回执再次说明；降至 65 以下解除疲劳扣减。摸鱼扣钱不叠加，养老金不受影响。原有收入数值规则未改。
- 加密交易室底部分为当前类别的持仓、成交记录、行情动态。持仓保留币种、成本/保证金、市值/权益、浮动盈亏、卖出/平仓；合约保留方向、杠杆及追加保证金。
- 新成交显示游戏日期时段、币种、操作、真实资金变动与已实现盈亏。买入/开仓没有已实现盈亏，显示“—”。部分退出、全部退出、每日结清、强平均按真实到账记账，结清不会重复出现。
- 没有准确币数、成交报价的旧存档不补造字段；旧成交保留原文与原交易日。行情不会把保留的成交记录挤掉：最多保存最近 30 笔成交，其余位置保留行情等记录，总数仍为 60。
- 长列表在模块内部滚动，短列表自然收高；手机表格变为带字段名的卡片。状态、底部菜单和原存档继续使用现有结构。

浏览器安全策略此前阻止了自动访问本地预览，本轮没有绕过限制。代码与行为测试另见 `reports/v1.53/verification.md`，实际屏幕视觉验收尚未完成。
