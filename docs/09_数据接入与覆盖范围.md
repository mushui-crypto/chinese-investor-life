# 数据接入与覆盖范围

## 当前交付

v1.1 已接入可玩的 0–80 岁人生系统。基础 180 个事件加灰黑产、网赌、法律后果、服刑与重返生活 24 个事件，共 204 个事件、614 个选项、910 个结果；另有 12 种家庭、12 位主要人物、24 个历史原型及 28 个结局。12 个人生主线和 24 个历史世界节点均已包含在事件总数内。

29 条结果分支带有明确后续预约。其余关联依赖当前年龄、资格、选择和状态进入候选池；司法阶段通知由实际案件进度插入，不能把它们全部误计为剧情预约边。事件池覆盖本版编写的路径类别，不穷尽现实，也不枚举所有可能的人生序列。

## 文件契约

| 文件 | 用途 |
|---|---|
| `data/events.json` | 全部剧情、年龄、资格、选项、权重、效果与预约。 |
| `data/effect_profiles.json` | 51 个共用效果模板；事件中已展开，运行时以事件效果为准。 |
| `data/content_manifest.json` | 当前总数与新增事件编号。 |
| `data/families.json` | 家庭权重、成年赠与、援助储备、开场属性。 |
| `data/characters.json` | 人物设定、代表对白及剧情关联。 |
| `data/history.json` | 历史日期、事实背景、来源与冲击通道。 |
| `data/legal_sources.json` | 责任区分的官方参考及来源核读范围。 |
| `data/endings.json` | 28 个结局的谓词、优先级、后记与开放方向。 |
| `data/state_sources.json` | 引擎派生标记、资格与关系条件来源。 |
| `data/event.schema.json` | 严格事件结构，按效果操作限定允许字段。 |
| `src/game/core.js`、`legal.js` | 实际账本、市场、行动、法律责任与服刑时间。 |
| `src/game/narrative.js` | 家庭开局、事件资格、固定结果、调度、历史冲击与结局。 |

基础内容源在 `scripts/build_content.py`，扩展源在 `scripts/build_underworld.py`。修改源后运行构建，不能只改生成 JSON。04/05/07/08 文档由同源生成，其余说明手工维护。Schema 由 `scripts/build_schema.py` 生成。

`profile` 用于追踪结算类型和少量专用语义，不能在展开效果执行后再额外发一次收益。`min_cash_yuan` 只是资格门槛，实际效果才转移资产。金额单位为整数分；内容里的 `*_yuan` 在 Core 边界转换。

## 资格、结果与迟到事件

候选事件检查年龄、标记、次数与场景范围；选择再次检查现金、资产、债权、债务、调查状态等实际资格。没有有效资产的出售、没有债权的追偿、没有未配合调查的配合按钮会禁用并给原因。

展示事件时已经为每个选项固定结果，存档保留结果编号与随机数状态。选择成功只结算一次，重复提交不会再次发钱。不同决策与行动顺序可以改变后续随机序列；这是本地单机可复现性，不是防篡改竞技存档。

主线跨年龄注册，不因超过原窗口自动消失。普通人生遇到危机或旧约会有限延后。服刑期间暂停外部事件和预约，释放后补读；晚年主线使用狱中正文，80 岁不因未完成的早期主线无限等待。具体规则见 [扩展说明](V1_灰黑产与服刑扩展.md)。

## 已实现的效果语义

- `family_transfer` 同时减少家庭储备，只转移实际可给金额。
- `freeze_investment` 扣本次投入、建立待偿权益，账面估值不等于现金。
- `recover_claim` 按真实剩余债权回收，不可重复超过剩余权利。
- `guarantee` 区分尚未触发的有限责任与已经被追索的债务，不假发现金。
- `extend_debt` 调整真实债务期限并保留本金、利息；不以减压代替偿债。
- `liquidate_asset` 出售真实可售资产，按折价和权属结算，锁定与冻结限制仍有效。
- `venture` 只处理本次新增投入；明确的额外赔付会形成债务。
- `illiquid` 生成锁定权益，估值增长不支付生活费，解除时间锁不等于已经兑现。
- `legal_case` 发放一次获利并登记案件，司法责任由时间推进；不能同批再用 `earn` 重复发钱。
- `legal_cooperate` 只作用未配合的现有调查；`quit_gambling` 区分首次拒绝、真正退出和重复拒绝。

## 覆盖与边界

| 维度 | 当前规则 |
|---|---|
| 家庭与成长 | 12 家庭、0–80 岁、成年赠与一次；家庭储备与个人资产分账。 |
| 生计 | 求职工资、零工、经营资产及利润、生活费、借贷与偿还。 |
| 市场 | 十类持仓，按各自流动性、到期、保证金和退出规则结算。 |
| 时代 | 历史回放有真实日期门槛；时代乱流每局 6–10 个历史原型，保留间隔。 |
| 冲击 | 仅作用相关敞口，每个世界冲击一次结算，不直接扣无关现金。 |
| 人际 | 伴侣、子女、信任和生活开支；配角不是各自独立运行的完整人生。 |
| 法律后果 | 7 类虚构案件、阶段通知、责任债务、服刑行动与释放恢复。 |
| 结局 | 28 条真实状态谓词，55–79 岁可以结算后继续，80 岁结束。 |

没有本金的狱外成年人仍有免费基础行动；服刑时有专属免费行动，任何阶段都不要求贷款后才能继续。全部 204 张卡至少保留免费且可行的退路。

行情并非逐日真实数据，人物对白并非自由对话，法律系统并非现实司法程序，开放后记中的未来方向并非额外可执行模式。当前实现的具体边界见 [V1 内容与实现边界](V1_内容实现边界.md)。

## 重建与检查

顺序执行 `python3 scripts/build_content.py`、`python3 scripts/build_schema.py`、`python3 scripts/validate_content.py`，再运行 `npm test`。结构报告写入 `reports/validation.json` 与 `reports/校验报告.md`；逻辑测试实际执行 Core 与叙事 API。

结构样例只能证明字段和条件有效。全结果执行、完整周目、存档往返、狱中释放等测试分别验证实际系统；浏览器可玩性与画面另见 [v1.1 验收与发布](V1.1_验收与发布.md)。
