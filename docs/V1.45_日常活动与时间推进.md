# v1.45 日常活动与时间推进

日常操作统一放在底部菜单上方。上方显示时段、生活费与当前事件，右下方选择活动；右栏保留作息说明、其他安排和近况记录。

## 活动与时钟

| 活动 | 完成后 |
| --- | --- |
| 吃早饭 | 09:30，进入上午 |
| 认真上班、上午求职、半天零工、学习、休息 | 11:30，进入午休 |
| 午休、散步 | 13:00，进入下午 |
| 下午工作、半天零工、家务、学习、休息 | 15:00，A 股收盘 |
| 收盘后活动身体 | 18:30，下班或傍晚 |
| 晚饭、学习、休息、晚班零工 | 22:30，准备睡觉 |
| 睡觉 | 工资与生活费结算一次，次日 07:00 |
| 熬夜看盘 | 次日 02:00；睡觉时结算熬夜影响 |

看手机、摸鱼看盘和查看账户进入投资市场，保留当前时段。上午/下午交易完成后点击“结束上午 / 结束下午”，推进至午休/收盘并返回生活页。夜间看盘优先进入已开放的加密市场；市场尚未开放则展示市场列表与现有开放条件。

工作中的直接交易也记为摸鱼。同一班次只检查一次被发现的风险，交易本身的疲劳沿用原规则。通过其他时间入口完成未安排的工作时段，仍承担正常工作疲劳；只有主动认真上班才获得对应本事增长。已有安排不重复结算，不追溯补算旧存档的历史日子。

上午求职成功后，从明天入职计薪，避免花半天找工作后领取全天固定工资。

## 随机事件、旧档与反馈

- 到达新时段可能遇到随机事件，显示在底部，焦点移到事件标题；选择完成后恢复该时段活动。
- 未处理的事件阻止活动与时间推进。接受加班到 22:30，拒绝加班可继续安排傍晚。
- 已完成活动的插图和属性结果仍可见；界面不再要求点一次继续来完成同一活动。
- 按钮携带所在日期和时段。过期按钮不能重复发工资、叠加属性或执行下一段的同名选项。
- 旧档中已选但尚未推进的活动，保留一次结束时段入口，效果不重复执行。
- A 股交易时段、T+1、交易费用和加密全天交易规则保持有效；生活费不提前冻结。

## 交易区布局补充

- 交易纪律改为横向状态栏，计算说明通过信息按钮展开，避免占用股票列表下方的窄列；列表、图表与下单区恢复等高。
- A 股、港股、美股切换按钮移除 T+1、日内可卖和起买股数。交易规则和实际校验保留。
- 指数百分比标注“大盘”，表示相对当日开盘的模拟指数变化；零涨跌使用中性色。
- 桌面与手机布局、三地切换、说明开关与存档不变检查见 `reports/v1.45/trading-status/`。

## 全局分割线与间距

- 股票列表取消个股图标；保留名称、行业、价格与涨跌。
- 大盘展开内容统一左边缘和分组间距，图表下方留出空间，交易规则使用共用按钮；纪律栏上方只保留一条分割线。
- 共用正文分割线统一为 1px，列表末尾与下一节之间不再重复画线。资产、记录、人物、账本与弹窗采用统一分节间距；深色交易室保持独立配色。
- 图表网格、游戏按钮、外部窗框与交互状态线保留。
- 检查覆盖七个主页面、十一种交易室视图、十二类常用弹窗，以及大盘展开与规则展开状态；桌面和 390 / 320 像素窄屏证据见 `reports/v1.45/dividers/`。

## 日常弹窗与收盘复盘

- 清除 flex 间距与通用弹窗段落、details、footer 外距叠加。已安排状态和结果合为一块，隐藏不可再选的活动。
- 工作区、操作区各一条分割线，折叠入口不重复加线；手机横向时间轴自动定位当前时刻。
- 15:00 后入口改为“查看收盘行情”，活动名改为“收盘复盘”；盘前、开盘时段、深夜入口分别标明含义。
- A 股收盘后下单和卖出提示次日 09:30 开盘，大盘日线与个股日线同步标记收盘；加密交易保持可用。旧档中的已安排选择和实际属性变化不重复执行。
- 检查见 `reports/v1.45/routine-dialog/`：1440、390、320 像素下的已安排、待安排、随机事件、规则展开、待业与退休、看盘返回和下一时段。

## 模拟练习改为自选

- 期权买方、期权卖方、杠杆合约和加密合约不再要求完成模拟练习；市场列表、条件详情与实际下单共用更新后的准入条件。
- 年龄、资产、眼力、参与经验和剧情条件继续生效。免费练习入口、练习收益和旧存档记录保留；首次投资引导不强制去练习。
- 零练习记录的四类产品实际下单与其他门槛检查，共 15 项浏览器验证通过，见 `reports/v1.45/optional-practice/`。

## 日结夜间过渡

- 单日结算后显示约 3 秒的全屏图片过渡。正常休息使用新绘制的夜间卧室图，镜头轻微移动、灯光变暗；熬夜使用深夜看盘图与轻微屏幕光。
- 时间沿用现有规则：正常休息为 22:30，熬夜至次日 02:00。画面显示本次结算的实际身体、疲劳和压力变化，随后回到游戏；不新增通宵时段或重算属性。
- 右上角可跳过，Esc 同样有效；系统或游戏设置开启减少动态时，显示短暂静态画面。图片加载失败会直接返回，慢加载也有超时退出。
- 工资、生活费和存档在过渡前完成。跳过、刷新、重复点击不会重复结算；生活费告急提示在过渡结束后出现，已有事件和人生结局优先。多日快进不逐日播放。
- 单元检查 42 项通过（市场准入、引导、作息与夜间过渡）。夜间浏览器检查 55 项、告急衔接 7 项通过，覆盖桌面、手机竖屏及横屏；证据见 `reports/v1.45/night-transition/`。

## 起床后的盘前浏览

- 07:00 的“醒来就刷行情”改为“看看盘前消息”，显示 09:30 开盘；完成后保留在 07:00，阅读不会推进股价。人物对白也按尚未开盘呈现。
- 盘前的 A 股桌展示最近市场消息、最近收盘价与历史日线；市场标签显示“未开盘”，个股与指数图隐藏当天的占位记录。已记录的历史价格、随机数和存档不变。
- 点击时间按钮到 09:30 后，回到上午安排，A 股允许交易。原有午休、收盘、T+1 与其他准入条件继续生效。
- 28 项单元检查、29 项浏览器检查通过，覆盖零历史、多日与旧档价格、手机与桌面、重复查看、推进到 09:30 后实际买入。证据见 `reports/v1.45/premarket/`。

## 上班期间的随机小事

在原有交接、工作差错、加班等事件上新增 10 类、20 个选择：电脑卡死、客户改需求、带新人、汇报漏署名、午饭被电话打断、上班犯困、工作群荐股、送材料、会议拖堂和帮同事收尾。日常事件池由 30 类增至 40 类。

- 仅在实际上班日出现。请假、待入职、待业、退休和学生不抽取在职专属事件；犯困要求疲劳至少 35，荐股话题要求已经接触股票。
- 09:30、13:00 的普通事件机会从 12% 调至 40%，其他时段仍为 12%。普通事件每天最多一件，加班单独检查，合计最多两件；优先避开最近六件事件，读档不重抽。
- 选择影响本事、自律、人缘、压力、疲劳等实际属性。咖啡花费 ¥12，地铁往返 ¥6，选前显示金额；现金不足时禁用付费选项，始终保留免费选择。扣款写入现金账本，重复点击不重复扣钱。没有增加固定工资或奖金金额。
- 事件使用现有工作、午饭、摸鱼和外出插画，在底部操作区处理，不另开弹窗；处理后恢复当前时段的工作与看盘选择。

438 项全量单元测试通过，211 项浏览器检查通过。另用固定随机种子检查 10,000 个在职日的事件调度：6,087 天在上午或下午遇到小事，单日均未超过上限；该抽样只检查触发频率，不代表收入或玩家体验预测。证据见 `reports/v1.45/work-events/`。
