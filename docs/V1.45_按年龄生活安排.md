# v1.45 按年龄安排生活

生活安排不再给幼儿套用成年人的学习、工作和社交活动。按钮、实际效果、结果文案以及快进成长使用同一份年龄配置。

| 年龄 | 探索或学习 | 休息活动 | 陪伴或交往 |
|---|---|---|---|
| 未满 1 岁 | 看看摇铃 | 吃饱睡觉 | 让家人抱抱 |
| 1–2 岁 | 摆弄积木 | 睡个午觉 | 和家人玩 |
| 3–5 岁 | 听故事、看绘本 | 去户外玩 | 和小朋友玩 |
| 6–11 岁 | 写作业 | 下楼活动 | 和同学玩 |
| 12–14 岁 | 复习功课 | 打球放松 | 找同学聊聊 |
| 15–17 岁 | 整理错题 | 出去走走 | 和朋友聊聊 |

## 效果与记录

- 未满 3 岁的日常活动不会增加学业；探索影响眼力见与自律，休息影响身体和压力，陪伴影响信任。
- 所有未成年日常活动都不会直接增加谋生本事、江湖名气、工资、现金或交易经历。
- 幼儿的家庭互动记录真实发生的玩耍与陪伴；和同学交往不会再被记成与家人吃饭。
- 成长偏好按年龄改名，学龄前不展示成年后的打工与交易效果说明。
- 每次仍消耗 1 次生活安排，成年后的活动规则保持原样。

## 存档和快进

保留原有 study / rest / social 操作标识，旧存档直接兼容；活动内容按当前年龄确定，过生日后自然切换。快进成长也经过同一套效果与记录逻辑。不会重新结算已完成的活动，或追溯修改旧档属性。
