# 中国式赌狗 v1.0 · 验收与发布

本文保留 v1.0 发布时的历史验收结果。当前扩展版本请看 [v1.1 验收与发布](V1.1_验收与发布.md)；源码中无版本后缀的报告文件会随最新检查更新。

发布日期：2026-09-22。版本：1.0.0。运行方式：本地浏览器单机；无生产第三方依赖。

## 本次交付

可以从出生玩到 80 岁的完整游戏。0–80 岁最多 90 回合，支持 12 种家庭、10 类资产、工作/生意/借款/还款、12 个主线年龄节点、180 个事件池、24 个历史原型和 24 种后记。结局同时匹配财富、债务、身体、关系与经历；55–79 岁查看后记后仍可继续。

界面使用原创生活场景与四年龄头像，参考《中国式家长》的养成场景组织；所有角色、场景和图形均使用本项目素材。页面包含生活安排、投资市场、资产账本、人情往来、人生小记、时代图鉴、设置，以及三槽存档。

## 实际浏览器验收

使用本机 Chrome 153 与 Playwright，通过真实页面控件操作，桌面 1440 × 950、手机 390 × 844。

`npm run qa:browser`：**34 项检查通过，0 页面运行错误**。固定种子 `release-browser-life-1` 实际经历 **90 回合、131 张事件、全部 12 主线，80 岁到达 E22 主后记**。记录位于源码 `reports/browser-qa.json`，截图位于 `reports/screenshots/`。

实际流程包含：

- 创建角色、出生剧情、刷新续玩、预定结果保存、童年学习、18 岁赠与。
- 求职、指定方向/10 倍杠杆/英镑敞口合约、精确扣款、资产曲线、自定义店名开店。

- 手机六功能页无横向溢出，历史来源可打开，Esc 关闭弹窗，减少动态设置保存。
- 55 岁后提前结算、保留持仓与债务继续、80 岁最终结算、24 后记图鉴、已结束人生刷新续玩。

另做了独立视觉检查并修复桌面场景宽度、手机标题场景裁切和小字号。以上属于 Chrome 桌面浏览器及手机尺寸模拟验收；没有把它表述为实际 iPhone/Safari 或所有浏览器认证。

## 使用与备份

Mac 双击根目录 `启动游戏.command`；或运行 `npm start`，访问 `http://127.0.0.1:4173`。需 Node.js 22 或更新版。`npm run launch` 会自动打开浏览器。

每次选择和操作后自动保存到当前浏览器。换设备、换浏览器、换地址/端口或清理浏览器前，在“人生档案”里导出 JSON。游戏不上传存档，不需要账户。直接双击 `index.html` 的 file 地址无法加载 JSON，请使用启动器。

`npm run build` 生成 `dist/`，可由静态服务器托管。发行包保留 WebP 运行素材，PNG 美术源图和测试留在源目录。核心源代码、数据、说明和美术都在本地项目，可以继续修改。

## 已知边界

本版使用离散回合的虚构行情与规则，不连接真实交易或提供现实胜率。180 张事件构成条件事件池，每局不会全部发生；所有基础结果均已接入，仍不能穷尽现实或无限组合。后记里的开放方向是叙事文本，实际续玩入口是“我还想再走一段”；80 岁以后可开启平行人生。长期数值平衡和更多场景/角色演出可在后续版本迭代。
