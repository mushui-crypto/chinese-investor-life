# v1.21 路线体验与界面精简

这次按已有路线逐项检查，没有新增市场。先修复阻碍继续游玩的地方，再减少重复说明和常驻面板。

## 已修复

- **求生被消息打断**：应急时，“继续”先结算一天。群聊和人物消息保留，脱困后仍能处理；当前主线选择和服刑规则照常执行。
- **市场里找不到生活入口**：投资首页和全部 11 个交易室都有“生活与账单”，可去打工、找出路、查看还款、人物约定和盘外消息。
- **普通输赢反复弹窗**：赌局普通结果留在桌面；现金归零、大额中奖、案件等重要结果仍单独显示，不会自动追加下注。
- **手机限额表单撑宽**：修正限额按钮样式误作用到数字加减按钮的问题。390 像素视口的弹窗原本内容宽 414 像素，修复后与 348 像素内容区一致；320 像素也通过检查。
- **店铺无法转让却不知原因**：生活安排用完时，在店铺旁显示原因；推进一天恢复安排后可以继续操作。

## 界面怎么收

生活页直接保留“找份工作 / 认真打工 / 接点零活”。学习、休息、朋友归为一组，目标、成长记录和小记归为“近况与小目标”，需要时展开；操作刷新后保持展开状态。小目标的历史完成标记改为“曾达成”，避免把过去的余额误认为现在仍够用。

每个交易室的下单区继续直接显示当前现金、本期剩余生活费、留足后的余额。压缩行距和重复说明，玩法与预留规则放进信息按钮；现金不足和生活费缺口仍能在下单前看到。股票整手、港美整股、手续费、实际现金校验和梭哈规则不变。

赌局缩短头部和玩法切换区，旧账移到桌面下方，去掉重复赌资金额。1440×1000 的普通龙虎斗下单，确认按钮现在位于底部导航上方；窄屏用“去下注”直接定位。停止参与、规则、历史记录都保留。

求生提示先显示每日支出、工资、现金能撑几天和脱困目标。详细失败条件与日结明细可以展开，借款、打工和变现入口保持可见。

## 自动体验范围

使用独立 Playwright 浏览器与测试存档，没有操作玩家正在使用的浏览器存档。覆盖两类检查：从开局推进的完整人生，以及为特定门槛、日期和事故准备的分支存档。

| 路线 | 实际检查 |
| --- | --- |
| 完整人生 | 12 家庭 × 工资、投资、反复风险后重建三种策略，共 36 局；推进到结局并往返保存 |
| 出生与童年 | 12 家庭出生故事、跳过、成年开局、二手集市、旧档继续 |
| 投资 | 11 个交易室；A 股 T+1、港股整手、美股整股，基金、债券、期权买卖方、期货、现货、100 倍日内合约、貔貅币、资金盘、天使轮和住房 |
| 赌局 | 龙虎斗、百家乐、斩龙、骰宝、轮盘、老虎机、红黑牌；真实下注、观牌、返还、归零与退出 |
| 生活与经营 | 打工日结、生活开支、人物约定、重建工作、开店、经营与转让 |
| 资金周转 | 家人、朋友、银行、网贷、信用卡、高利贷；逐一申请、核对净到账与本金、读档、实际还款 |
| 盘外事件 | 13 段事件入口；瞒债发现、群聊、黑平台、误工、限额、冷静期与恢复 |
| 案件与结局 | 行政处理、调查、判决、服刑、出狱再求职、七天失败、普通与风险结局、重载不重复清算 |
| 交互 | 桌面与 320/390/768 像素；键盘、信息弹层、游戏表单、折叠后入口、固定导航和焦点 |

源站检查包括 266 项单元测试；内容校验覆盖 219 个事件、659 个选择、966 个结果分支和 32 个结局，10,657 项静态检查通过。浏览器报告和截图保存在开发项目 `reports/v1.21`，最终构建验收记录见其中的 `release-manifest.json`。

这是对路线种类、关键分支和边界的覆盖，不等于穷举所有随机数与选择排列，也不是玩家留存或“七成时间在市场”的真人数据。各路线的金融结算、旧债、生活账单以及已有清算尾声规则沿用现有版本。
