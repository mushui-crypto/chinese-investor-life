# v1.30 内容区独立滚动

游戏进行中，只有顶部人物信息和底部导航之间的主内容区上下滚动。桌面上的属性账本、生活安排与近况面板保留原位置和边距。侧栏内容过长时仍可在侧栏内滚动。

主内容区根据实际导航高度留出空间，最后一项不会被导航挡住。窄屏将生活安排接在主内容后面，头像和底部导航仍留在视窗内。标题、出生开场和结局页保持原来的阅读方式。

“去下单”“看持仓”“行情 / 资料”和剧情焦点随新的滚动区定位，避让交易工具条。关注项目、买入等操作刷新界面后保留滚动位置；普通下单继续保留输入金额。说明气泡会在页面内容滚走后收起，下拉菜单继续使用原有的独立弹层。

这次调整不改变游戏时间、交易规则和存档格式。
