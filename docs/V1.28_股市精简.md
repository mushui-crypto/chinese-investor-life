# v1.28 股市精简

股市围绕看行情、买入、卖出和持仓展开。

- 移除订单抽样、回款核查、供应商访谈、公司资料、公告复盘与行情卡。不再提供调查或出牌操作，旧卡片也不会继续影响价格。
- 股票交易日记移出页面，现金和买卖仍正常记入原有账本。
- 保留 A 股、港股、美股切换，个股报价与走势图，市场消息，以及买卖与持仓。继续按钮负责推进行情和进入下一交易日。
- 保留 A 股 T+1、港美股日内可卖、各标的交易单位、卖出费用和每日共享 6 次操作。
- 生活费仍只提醒，允许梭哈；现金不足和交易规则照常拦截，之后的账单和求生规则继续生效。
- 清理成长方向与新开局中的调查加成说明。童年的属性积累和动手方向每期首次临工加成保留。基金、债券、天使投资等市场的资料操作保留。

旧存档无需转换。旧行情卡、调查和公告记录仅保留为兼容数据；不再发卡或新增公告复盘。旧档中尚未结算的卡片影响不再生效。原有现金、持仓、债务、人物和剧情进度不因加载改变。

本次 QA 记录保存在源码目录 reports/v1.28/qa，测试使用独立浏览器存档。

验收通过：269 项单元测试，以及三地股票、全部交易室、旧档、生活费与梭哈、全局生活推进、童年、操作反馈和人物界面的针对性回归。股票覆盖 320–1440px。详见源码目录 reports/v1.28/QA验收报告.md。
