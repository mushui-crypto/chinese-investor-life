# v1.56 阶段生活主流程

成年首页改为阶段选择、关键事件、阶段结算。取消亲自体验 3 天的前置条件，收起逐小时活动和“安排几天作息”。成年仍有 34 个人生章节：18–36 岁每年一章、36–60 岁每两年一章、60–80 岁每五年一章；原半年/年度账期保留为内部财务与剧情节点。童年关键学段不变。

## 玩家的操作

1. 在底部选择这段时间的生活重心。
2. 可去投资市场自由交易、处理人物和工作；或直接按“推进生活”。
3. 插画和日期显示普通日子过去。遇到需要决定的事情停下，显示真实收支和属性变化。
4. 处理完继续同一阶段；到达下一章后重新选择生活重心。

“展开今天”保留当前实际时刻，供主动交易、睡觉、午休、兼职和熬夜使用。返回阶段安排不改变时间。进入交易室仍按实际市场时段买卖，阶段选择不消耗或限制交易次数。新开成年人生、读档和主线结束回到生活首页。

## 生活重心

| 选择 | 执行效果 |
| --- | --- |
| 按部就班 / 踏实工作 / 安稳生活 | 保留身份对应的普通日常和固定收支，不自动求职或额外接活 |
| 学习 / 提升本事 / 培养兴趣 | 学生每累计 30 个自动生活日学业 +2、自律 +1；其他身份本事 +2、眼力 +1 |
| 课余 / 下班兼职 | 每个七日周期安排两次晚班；沿用手动兼职的工资、疲劳减薪、健康与当日接活上限；已安排的时段不覆盖 |
| 多陪身边的人 | 每累计 30 个自动生活日人缘 +2、压力 −3 |
| 多留意市场 | 每累计 30 个自动生活日眼力 +2、疲劳 +4；不自动建仓、平仓或借钱 |
| 把状态养回来 | 每累计 7 个自动生活日健康 +1、疲劳 −6、压力 −2；缺食时不能靠休整恢复健康 |

选择只作用于接下来自动经过的日子。切换与重新选择不发钱、不加属性、不推进日期。各重心累计天数分别保留，避免切换刷奖励；一个阶段结束后重新累计。普通上班的疲劳及正常睡眠的恢复继续计算，养老金规则不变。

## 事件和资金

普通日常按章节长度挑选约三个代表片段，长章节不会逐月重复同样的小事。人物已触发的后续、消费消息、工作变动、健康、约定、到期还款、重要持仓变化不受这个数量限制。事件匹配身份；事件出现后仍需玩家选择。

推进前核算当日固定收入和已明确选择的兼职计划；不足以付生活费或到期款时停在扣费前。预估收入不是现金，实际完成兼职后才入账。暂停不会重复扣费，已做的选择、工资和兼职记录随存档保存。界面提供安排生活费、还款、持仓和约定入口，不自动变现或借款。

熬夜影响沿用原规则：睡过头到 11:30、上课迟到扣属性、上班迟到扣工资；职员熬夜后是否出勤交给玩家决定，阶段推进不能替答。手动日内操作仍可承担资金不足的后果。

## 布局与兼容

阶段操作继续放在底部，中央保留场景。初次展开生活重心选项，选好后折叠；生活收支按需展开。桌面三列选择、窄容器两列/单列，底部面板沿用可用高度上限和独立滚动。

阶段概览使用与身份、生活重心对应的代表插图；展开今天与实际事件使用当前时段插图，不改变交易时钟。过场和减少动态设置沿用原有实现。

旧档不需要重开。原 chapterPace 和 routinePlan 仍可读取，但不再作为 UI 门槛或入口。新增 stagePlan 仅在选择后保存；读档不会自动恢复推进。账本与随机数在选择或渲染界面时不额外变化。
