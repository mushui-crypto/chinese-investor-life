# v1.57.7 投资市场界面与金额

沿用纸张、木框与深绿操作色，币易交易所维持深色终端；按 impeccable 的审阅流程调整留白和信息层级。11 类细分交易页使用一致的标题、资料、下单、持有资产、记录顺序。基金、债券、创业股权、熟人项目和房产的资料改为对齐的项目事实行，减少嵌套卡片与重复说明；窄屏按单列流转。

## 输入与房产

- 全局数字控件移除加减按钮与浏览器原生步进箭头，使用合适单位的预置值，并保留手动填写。金额按元、股票按手、数量按件；预置值遵守上下限和步长。骰子点数与轮盘号码改为明确选项。
- 房产先选择总价，再选择全款或首付 30% 按揭；不再使用现金百分比或梭哈选项。展示本次支付、付款后现金、新增按揭、首月月供与出租收支。
- 房屋总价以分为精度，首付与贷款之和严格等于总价。持有房产单独展示估值、买入总价、剩余按揭、房产净值、租金和可出售时间。
- 售房回执区分扣费后房款、偿还按揭与净到账，未清欠款继续保留。

## 交易常识修正

资金盘、房产、创业股权和线上赌局不再套用证券交易日、收盘时间和交易次数限制，操作不自动推进证券时段。资金盘可随时申请投入或提现；提现仍可能失败并转为债权，账面收益不等于现金。

保留实际现金、市场准入、信用、房产与股权锁定期、合约到期、退出意愿和案件后果。股票 T+1、基金赎回与证券交易时间仍遵循各自规则；未把所有项目统一成全天自由卖出。
