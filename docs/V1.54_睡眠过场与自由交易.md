# v1.54 睡眠过场与自由交易

## 睡眠与起床

“连续熬夜归零”改为“结束连续熬夜”。它只结束连续熬夜记录，不把疲劳清零；正常睡觉疲劳 −12。

熬夜结算时一次性抽取次日起床结果，存档后不重新抽取。第一次熬夜有 30% 概率睡过头，连续第二晚 45%、第三晚 60%、第四晚起最高 75%。不熬夜不会抽取迟到结果。

- 正常睡觉：次日 07:00 起床；疲劳仍高时显示尚未缓过来的状态。
- 熬夜但闹钟叫醒：07:00 起床，保留现有疲劳与熬夜后请假、旷工选择。
- 熬夜并睡过头：直接进入 11:30 午饭休息，07:00 与 09:30 的活动均跳过。无法补选早餐、上午上课或工作，也不能再接全天零工。A 股处于午间休市，持仓和行情照常结算错过的上午。
- 大学生：学业 −2、自律 −1，不扣钱。
- 在职：当天工资扣 10%，自律 −1、人缘 −1；工资扣款随当日日账结算，既有疲劳/摸鱼扣减与迟到扣减分别计算。不把这次迟到再记为一次旷工。
- 待业与退休：只跳过上午，无迟到扣钱或属性处罚；养老金不受迟到影响。

迟到事件在玩家选择后只结算一次。批量推进、日历、市场和常用作息入口都会停在待处理事件，避免直接扣完整个新的一天。月末不会把已扣的迟到工资补回来。

## 画面与轻动画

使用内置 image_gen 新生成六张 1774 × 887 插画，保持 2:1、同一卧室与人物风格。原始 PNG 保存在 `output/imagegen/v1.54/`，游戏加载对应的 WebP。

| 入睡素材 | 使用情形 |
|---|---|
| sleep-calm-v2 | 正常入睡，人物安稳躺下 |
| sleep-reading-v2 | 正常入睡替换，合书关灯 |
| sleep-late-v2 | 熬到两点后疲倦睡下 |

| 起床素材 | 使用情形 |
|---|---|
| wake-fresh-v2 | 按时起床、疲劳低于 40 |
| wake-alarm-v2 | 熬夜后被闹钟叫醒，或正常睡眠后仍然疲倦 |
| wake-overslept-v2 | 熬夜睡过头，11:30 起床 |

两张正常入睡素材按游戏日轮换；起床素材由实际保存的状态决定。每段约 2.4 秒，使用轻微镜头移动、变暗和晨光渐入连接睡眠与起床；支持跳过、Esc、系统和游戏内减少动态效果设置。图片缺失或超时会跳过，不改变日账、随机数或起床结果。

原始提示词：`output/imagegen/v1.54/prompts.json`。素材映射：`output/imagegen/v1.54/assets.json`。

## 移除交易限制

删除“状态与消息”中的“交易限额与休息”整块，包括每日投入上限、冷静 7/30 天和此处的休息入口。剧情不再设置限额或暂停新增交易；相关选项改为记账、复盘与安排生活，只影响已显示的属性和故事记录。旧存档的限额、冷静期字段保留用于兼容，但不再限制任何交易或暂停快进。旧按钮命令会返回功能已移除，且不改变状态。

睡觉、午休、疲劳及其收入后果保留。实际现金、费用、交易单位、开闭市等市场规则继续生效。
