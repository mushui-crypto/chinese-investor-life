# v1.48 全局高度适配

- 通用工作区取消 670 / 550 / 500 像素的固定最小高度。市场列表、资产、记录和案卷随实际内容收高，保留统一内边距。
- 长列表继续在中央内容区滚动，人物资料、侧栏和底部导航保持原来的位置。
- 童年安排、日常活动和待处理事件按窗口实际可用高度限制操作区，过长内容在操作区内部滚动。按钮与文本不压缩，不挡住菜单。
- 手机矮屏（宽 360–900、高不超过 740）将底部菜单改为一行文字按钮；横屏低于 500 像素时人物资料改为横向紧凑布局。菜单保持完整功能名和至少 44 像素的按钮高度。
- 弹窗继续按内容自然收高，长内容在固定标题下滚动。

## 验证

使用独立的 4174 端口测试存档，不修改玩家存档。检查七个主页面、十类市场桌、人物资料/设置/作息弹窗及童年安排。覆盖 1536×864、1280×600、390×667、844×390；长表单、短列表与底部操作滚动另行检查。布局证据位于 reports/v1.48。

本轮没有改动经济、市场开放、交易结算或成长数值。相关童年场景、日常作息与夜间过渡共 20 项单元测试通过。
