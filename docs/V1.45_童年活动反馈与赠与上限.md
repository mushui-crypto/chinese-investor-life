# 童年活动反馈与赠与上限

## 活动

- 按钮显示本次实际可获得或损失的属性，计入本学段剩余年数、成长衰减和属性边界。预览不推进时间、不消耗随机数。
- 完成后在底部操作区显示活动名和实际增减。每项仍消耗 1 点精力，每学段共 2 点；推进学段不自动补选。
- 小学：上课做作业、放学玩耍、和同学玩。
- 初中：复习功课、课后运动、和同学聊天；新增偷玩游戏、和家里顶嘴。
- 高中：保留备考、运动、朋友活动；新增逃课去网吧、躲着熬夜玩。
- 叛逆活动可减轻压力，同时损失学业、自律、人缘或健康。网吧活动另花费 ¥30，现金不足不能执行。小学不开放这些选项。
- 初中机器人社团故事改为班级黑板报，保持已有事件 ID、权重和结果数值。

## 周末二手集市

- 每批仍为 1–3 件，最贵的卡带每批进货最多 ¥144。
- 初中、高中各接待最多 3 位买家，不再共用整个童年的 3 次额度；摆摊仍不消耗生活精力。
- 旧存货可以继续处理，已经生成的买家报价不会因升学、刷新或读档重抽。升学前的报价处理完后，才使用新学段额度。
- 新增手动按进价五折清仓；成年时的自动清仓继续保留。

## 家庭赠与

- 成年赠与仍在 18 岁发放一次，所有家庭上限均为 ¥100,000。家庭储备不直接计入个人现金。
- 新开局区间：拆迁家庭 ¥50,000–100,000，专业人士和实业家庭 ¥30,000–100,000，富裕家族 ¥80,000–100,000，老股民家庭 ¥10,000–80,000；其余原区间均未超过上限，保持不变。
- 尚未领取赠与的旧档直接限制待发金额，不重抽随机数。
- 刚到 18 岁、赠与后没有新现金流水的旧档，将超额赠与交回家庭储备，保留此前存下的钱，并补记一条反向流水及调整记录。重复读档不重复扣款。
- 已经交易或继续成年人生的旧档不倒推回滚交易，也不制造欠款；历史收款记录保留。
