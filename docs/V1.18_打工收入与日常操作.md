# v1.18 打工收入与日常操作

本次自行排查发现，求生期接完一单、恢复生活费后，同一天剩余的打工可能按整期发钱；普通日历刷新生活安排，也可能重复领取一批工作的收入。这会放大爆仓后的回款，混淆一天与半年的代价。

修复后，本期一旦开始日结工作，脱困、切换页面和读档都继续按日结。进入下一期时才恢复原有批量接活。逐日工作和逐日交易分开记录，安静的日子仍能快进，不要求玩家逐一点击半年中的每一天。

打工按钮直接显示本次实际到账金额，包含疲劳扣减与童年接活加价；手机版和平板不隐藏工钱。普通打工和零活在页面显示结果，减少反复关闭弹窗。固定岗位工资仍随时间到账。

## 已验证

- 253 项单元测试通过，包括六项新增工资与时钟回归。
- 36 条完整人生流程走到 80 岁，覆盖十二种家庭及工作、投资、重建路线。
- 求生浏览器检查 29 项、全流程界面检查 57 项通过。
- 新增 23 项浏览器检查覆盖实际支付、求生脱困后第二次打工、存档重载、日历刷新与 1440 / 768 / 390 / 320 像素布局。
- 由 v1.17 引擎生成的普通、逐日和求生存档均能读入，钱、资产、欠款、随机数、年龄与剩余操作次数不变。
- 生活费仍只作交易提醒；原有股票交易单位、工资补结、借款、账单、求生失败规则继续执行，不自动补钱或出售持仓。
- 自动化在独立浏览器环境运行，没有改动玩家正在使用的存档。

## 平衡检查的边界

本次修复不等于已经完成“网赌最终必归零”。当前规则仍允许停止网赌后靠工作重建，也不能把一次现金为零当成整个人生破产。

自动人生样本的结局净资产现在计入未结案件账单，同时保留原账面净资产，方便核对。现有样本每期只操作三个重点交易日，之后仍有工资和开支结算；它不是每天持续赌博的模拟，也不能用来宣称玩家的真实破产率。完整结果和待完成项保存在源码项目的 `reports/v1.18/`。
