# v1.60.0 · 藏在人生里的网赌经历

本次在现有事件池、人生时间、存档、财务账本和结局页上扩展。童年弹珠、学生旧事、升学、工作、婚恋与投资市场仍使用原流程。新增 27 个节点，不把它们排成连续章节。

## 触发与时间

- 18 岁以后才可能接触。首次「群里的链接」无论如何选择，完成后都回到日常；拒绝会降低未来权重，并进入较长冷却。
- 新节点沿用现有随机候选池及事件槽，不插入保底事件，也不指定下一节点。资格由年龄、当前状态、实际回执和历史记忆决定，抽取权重再受行为倾向、童年经历与拒绝次数影响。
- 两次相关故事之间至少经过 90 个游戏日和 2 件已完成的普通事件；同一事件另有 180、360 或 720 日冷却。时间使用原有单调人生时钟；切换市场日期不会缩短冷却。
- 退出通常冷却 180 日，后续遇见的权重降到原来的 22%；拒绝次数还会进一步降低。恢复生活后只保留两类低权重回忆，至少冷却 720 日。
- 元数据支持 `requiredState`、`blockedState`、`weight`、`cooldown`、`minDelay`、`ageStage`、`memoryTrigger`，另有普通事件数量与可重复标记。
- 旧存档里已经打开的旧网赌故事仍可完成；新的抽取不再走旧的连续 UG 事件链。旧事件数据未删除。

## 钱、结果与记忆

使用原有整数分账本及随机数源，选择的候选结果在事件出现时锁定，读档不会重新抽签。没有新设可与现金混淆的持久平台余额。

- 一次性 20 元试用额度不扣现金、不产生债务；用完后不能重复领取。可提现回款计入现金。
- 真钱小额选项通常 20 元；加注、追损及全部投入随实际现金和上次投入变化，选项明确显示金额。现金不足保留免费退出，不凭空补钱。
- 借 100 元必须由玩家明确选择，并通过原有借款资格检查；进入已有熟人借款账本，无息、三个月还款。借来的钱赢了也不会免债。
- 随机结果包括小赢、小输、大赢、归零、持平；大赢保持低概率。主动追损、过度自信等改变相应结果权重，不保证第一次输钱。
- 下注与返还分别记入现金流水，实际净盈利减压，亏损或冒险失败增加压力。普通投资不会被当成复赌。

长期倾向保存在既有 `behavior` 下。首次下注、首次赢、首次大赢、首次输、首次追损、首次借赌资、首次回本、首次债务、首次退出、首次复赌和最高盈利分别记录；同时保留最长退出时间和实际选择时间线。旧赌场总账可接入，但缺失的首次年龄不会伪造。

## 退出、恢复与后记

每个重要节点保留免费离开。退出后不自动清除资产、债务、工作或家庭，也不自动安排一笔最终亏损。

`RECOVERED` 需要：至少 720 日没有重新参与、退出后至少两次拒绝再次参与、没有新增参赌借款，并已偿还退出时主要债务的至少 80%。恢复后回忆节点与既有赌场都不能再下注。尚未完成恢复的严重追损者不会提前显示「上岸」。

13 类阶段后记：没点开的链接、几十块买来的教训、拿钱走人、娱乐玩家、把运气当成运气、上岸、反复横跳、赢了但没走、回本以后、理论大师、老师毕业了、债务循环、爆仓破产。它们依据实际行为与财务结果展示，不替代原有 33 个整个人生结局。

个人资产或生活费暂时不足不单独构成网赌破产；需有相应的真实亏损和升级行为。普通生活债务不归因于一笔小额娱乐。严重追损或借款后刚停止，不立即授予成功退出后记。

## 展示与兼容

新增插曲放在屏幕下方文字事项区，复用自适应两列选项。主要人生事件继续使用原有配图。人生小记、原赌场账本和结局页可查看「这段经历」，结局默认展开：累计下注、提现、净输赢与净亏损、历史最高及最终资产债务、首次经历、戒赌和复赌记录。

「你曾经有 X 次离场机会」只统计真实遇到的选择；抽取横跨人生的关键记录，呈现当时年龄、累计盈亏和玩家选择。已恢复的纯回忆不增加虚假离场次数。导出人生小记包含同一份账目。

存档沿用既有版本与校验，补入缺失状态；原有赌场、法律后果、普通交易规则继续有效。重复故事使用独立实例编号，避免旧的已完成事件拦截后续，也防止重放同一回执。

## 验证

- 机制、实际赌场桥接、随机调度、故事文案、存档与结局均有回归测试；以 `npm test` 为完整入口。
- `npm run check:content` 校验全部事件、选项、效果与条件。
- `npm run qa:online-gambling` 使用隔离浏览器存档，验证桌面、小屏、手机的底部故事、实际输赢、读档和人生账本，不操作用户当前进度。
- `npm run qa:online-pacing` 通过真实人生入口跑固定种子的 20 局，禁止直接塞入 OG 队列；仅设置测试用资金与健康下限以隔离生存失败。此次 20 局均走到 80 岁，每局 2–10 次相关事件，未出现冷却或普通事件间隔违规。此抽样验证叙事节奏，不代表未干预经济平衡的通关率。
