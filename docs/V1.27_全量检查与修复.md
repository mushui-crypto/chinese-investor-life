# v1.27 全量检查与修复

本次先检查遗漏，再修复实际发现的问题，最后对运行包执行项目全部自动化 QA。保留完整插图、两侧留白、左下人物、右侧生活安排和全部底部菜单。

## 已修复

- **配图加载跳动**：图片下载前保留原始比例的空间，加载完成后正文和选项不再突然下移；完整画面和上下结构不变。
- **剧情键盘操作**：选完后直接读结果，继续后进入新故事；Tab 可接着选择，选项避让底部固定菜单。
- **下单后焦点丢失**：数字输入框被包装为游戏控件时保留焦点，Enter 下单后可继续编辑数量。
- **手机股票首屏**：减少重复的人物和现金概要，股票改为单列横向报价，名称与价格一起展示。人物资料仍在头像里，三项资金金额仍在下单区。
- **桌面赌局**：收紧少量内边距，普通下注确认按钮不被底部菜单盖住。

本次没有修改投资、生活费、工资、债务、求生、概率或结局规则。与 v1.26.2 运行包逐文件比对，38 个引擎与数据文件完全一致。

## QA 方法

新增 `npm run qa:all`，统一运行现有模块测试、内容校验、整局模拟、随机操作、浏览器流程与存档兼容检查。每套测试单独保存日志与报告。浏览器测试使用独立环境，不读取或覆盖玩家当前标签页的存档。

同步修正旧测试中已改版的入口和文案：童年与成年使用统一继续入口；阶段目标在近况折叠区；开放条件通过信息图标查看详情；重大时刻在生活页查看。原有金额、状态变化、成交、清算等断言继续保留。

慢速图片、键盘阅读和六档屏幕宽度增加独立回归检查。原有规则包括实际现金限制、梭哈单位、生活费仅提醒、T+1、结算与求生仍由原有规则测试和浏览器流程验证。
