# v1.5 每日生存与失败规则

## 评定

“一天付不起就立即失败”过于苛刻。股票 T+1、被冻结的资金、长期股权，以及当天刚爆仓，都可能造成暂时没现金。如果直接结束，打工翻身这条路线几乎没有操作空间。

默认采用 **每日生活账 + 连续七天欠费 + 可变现能力复核**。保留资金压力，也让玩家有时间改变选择。失败代表本次游戏无法继续维持基本生活，不将负净资产直接等同于死亡。

## 默认开销

按既有月度生活费折算，每日向上取整到分。本作统一按每月 30 天计算，金额是游戏参数，不是现实城市的生活成本调查。

| 条件 | 月度基本开销 | 参考日开销 |
|---|---:|---:|
| 成年、独自生活、无自有住房 | ¥1,800 | ¥60 |
| 有仍具价值的自有住房 | ¥1,400 | 约 ¥46.67 |
| 有伴侣 | 另加 ¥600 | 另加约 ¥20 |
| 有孩子 | 另加 ¥1,200 | 另加约 ¥40 |
| 55 岁后仍需赡养在世父母 | 另加 ¥500 | 另加约 ¥16.67 |

未成年生活由家庭承担，不开启个人生存倒计时。服刑期间暂停个人每日生存判定，并中断此前的连续欠费计数；既有家庭开销、案卷与债务仍按原规则处理。退休金按已有工资字段计入每日可用收入。

## 每日记账与压缩时间

- 正常交易日收盘时，先结算当天工资，再扣基本生活费。工资按月工资的 1/30 向下取整到分；不提前计入尚未发生的投资收益、经营利润或项目退出款。
- 已日结工资和全部已记账生活费，包括尚欠的部分，分别从本期工资与生活费总额中抵扣。欠款保留在债务表，不重复新增。日结工资不会因之后的收入冲击被倒扣，未发部分按原阶段收入规则补结。
- 每个交易日只记一次账，开盘、盘中点击、切页、读档不重复结算。挂机不会计时。
- 正常人生仍按半年或一年压缩推进。阶段结算发现现金不足时提供应急机会，不把跳过的半年直接判成 180 天断粮。
- 应急期间“进入下一期”改为结算一天，不跳过半年 / 一年；收盘仍处理当日行情和到期合约。已度过的应急日计入本期日结总账，不额外增加同一期费用。
- 每次应急日结恢复两次生活安排；应急状态下可继续开启下一交易日，股票 T+1 和合约当日结算照常执行。应急零工按 **¥120 + 谋生本事 × ¥4** 结算一天的小单，不发半年的零工收入。普通阶段保留原来的成批接活规则。

## 什么时候失败

现金加当天可得工资不足一天生活费时，显示应急面板。开始时尚未消耗七天窗口，每完成一次真正的日结再检查：

1. 当天没付清开销，连续欠费天数加一，差额进入生活费欠款；最多显示七天。
2. 完整支付一天会中断连续欠费记录；部分支付不能中断。
3. 第七次连续欠费后，若**现金 + 每日工资 + 当前可变现资产净额仍不足下一天开销**，触发 E29「最后一碗面，没能续上」。
4. 若还有足够可售资产，不误判为无力生存，面板提示先处理现金缺口；资产不会未经操作自动卖出。
5. 找到工资足以覆盖日开销的工作，或备足七天现金生活费，可退出应急阶段并清除连续欠费计数。原有欠款、贷款、罚款和案卷不会随之消失。

可变现净额尊重 T+1、停牌、冻结、锁仓和费用；房屋先扣对应按揭，店铺按实际八折转让额计算。资金盘账面余额、追偿债权、保证金义务不明的卖方期权不计作可靠饭钱。家庭储备属于家人，成功借到后才属于可用现金。

七天内可以接日结零工、求职、出售已可交易资产，也能按既有规则借款。没有自动发放的无限救济金，也不会因现金为零、负净资产或短暂锁仓立即结束。

## 失败后与旧档

E29 是终局，不显示普通后记的“我还想再走一段”。仍可保存、导出档案，或开启另一段人生。其余 28 个开放结局及原来的继续人生规则保留。

旧档新增的日结账本与连续欠费天数从零开始。导入本身不收钱、不补算旧版缺失的每日记录，也不立即判失败；原有现金、负债和随机状态保留。

## 验证与边界

规则测试覆盖日结与半年结算不重扣、七天失败、完整支付中断、现金为零但有工资、资产可变现与锁仓、T+1 应急出售、负债保留、存档损坏拒绝和旧档迁移。浏览器验证实际按钮、结果页、读档及 320–1440 像素布局。

另用 12 个家庭、每家两个种子，共 24 个完整人生模拟作平衡回归：采用避免高风险邀约、收入不足时求职、必要时接零工的固定策略，全部到达 80 岁。这只能说明基础生存路线可走通，不能代替玩家试玩，也不代表所有冒险路线都能幸存。

本次验收：135 项规则与存档测试、10,648 项内容校验全部通过；v1.0–v1.4 的 17 个旧档场景迁移通过。231 项发布目录浏览器检查涵盖完整人生、投资市场、赌局、法律后果和每日生存，均无运行错误。
