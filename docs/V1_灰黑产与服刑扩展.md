# 中国式赌狗 v1.1：灰黑产、网赌与服刑扩展

这次扩展把“赚到一笔快钱”之后的调查、裁定、债务、服刑和出狱接入同一段人生。玩家可以拒绝诱惑、继续谋生，也可以在明知违法的选项中获得夸张收入，随后承担不会因关掉故事而消失的后果。

当前共 **204 个事件、614 个选项、910 个结果、29 条剧情预约边、28 个结局**。本次增加 24 个事件、72 个选项、87 个结果、9 条预约边及 4 个结局。内容池不代表每局都会经历全部事件。

新效果模板为 `uw_gamble`、`uw_chase`、`uw_promote`、`uw_account`、`uw_fraud`、`uw_data`、`uw_fund`、`uw_ads`、`uw_quit`、`uw_victim`、`legal_cooperate`、`prison_study`、`prison_reflect`、`prison_letter`。全部新事件最低年龄为 18 岁；现金不足会禁用付费选择，免费退路仍然保留。

故事只呈现动机、选择、收入和反噬，不提供犯罪渠道、技术步骤、话术模板或规避调查的方法。刑事选项明确写出明知或主动组织参与。受骗、账户出现异常、单纯投资亏损，不自动等于犯罪。

## 案件怎样推进

`legal_case` 同时发放本次非法获利并登记一条案件，不再用 `earn` 重复给钱。新案在第 2 个后续回合出现线索，第 3 回合进入调查，第 4 回合裁定；这是固定游戏节奏，存读不会重抽，也不会因玩家拒绝再参与而删除旧案。

案件状态是 `pending → exposed → investigating → convicted/admin_closed`。每阶段有人生记录；剧情调度插入相应通知。配合调查只在确有未配合的调查时开放，不会对已经完结的案子显示一个仍能减免责任的假按钮。UG11 也要求已有调查。

违法所得追缴、罚款和退赔分开结算，先扣可用现金；不足部分分别生成法律责任债务。每案只结算一次，不把罚款当投资亏损，不把未付退赔清零，也不会自动为玩家申请贷款。主动清偿、出狱就业与后续谋生可以继续改善账本。

本版 `gambling` 是个人参与的行政处理情节，`misleading_ads` 是行政营销情节。明知组织推广网赌、协助犯罪出租账户、欺诈、非法数据交易和非法集资使用刑事故事。这里不模拟现实全部构成要件，也不意味着所有赌博参与或营销行为在现实中都只承担行政责任。

## 服刑与释放

服刑时保留年龄、全部资产、债务和案卷，暂停外部求职、经营、借贷、交易及关系安排。固定工资与店铺收入停止；已存在的被动资产和债务仍按 Core 规则结算，历史冲击仍只作用于相关敞口。

剧情只展示监狱、相关法律场景和适配的晚年主线。普通生活主线、未读外部事件与预约等待释放；已结算的世界冲击新闻可以迟到阅读，但不会再次扣钱。看完全部狱中一次性故事之后仍可以使用学习、反省、家书等日常行动或直接推进时间，不会卡住。

剩余刑期短于正常回合时，时间推进切到剩余月份，因而可能出现小数年龄。释放会插入 RE01，随后恢复外部行动，成功求职登记 `reentry_employed`。出狱不会抹去法律债务，也不自动送来一份高薪工作。

60、70、80 岁主线提供狱中正文。80 岁即使还有刑期或延期未读的早年章节，也可以完成当前晚年章节并结算。55–79 岁查看后记后仍能继续原人生；所有未完成责任继续保留。

## 虚构参数与参考范围

所有获利金额、概率、罚款、退赔、阶段间隔和刑期都是游戏参数。案件采用固定类型规则，不是现实法律金额计算器；不模拟完整取证、庭审、上诉、合并量刑或减刑程序。

责任区分参考最高人民法院发布的 [关于办理帮助信息网络犯罪活动等刑事案件有关问题的意见](https://www.court.gov.cn/zixun/xiangqing/472121.html)：判断应结合主观认知、实际帮助行为和具体情节，不能只看到某个表面行为就一概归罪。本游戏据此在故事中明确“明知帮助”与“不知情受骗”的区别，不照搬现实定罪门槛。

关于参与赌博和组织经营的区分，参考最高检网站转载的 [线上赌球：法律风险有多大？](https://www.spp.gov.cn/spp/llyj/201806/t20180630_383369.shtml)。它是 2018 年的历史讨论，本文未将其中旧处罚数额作为现行规则。官方搜索缓存可核读，直接页面访问返回 403。另保留 [网络赌博案件原始规范参考地址](https://www.spp.gov.cn/spp/nbgz/201802/t20180201_363851.shtml)，本次直接访问同样返回 403，未据此复述未读正文。来源记录保存在 `data/legal_sources.json`。

## 内容维护与验证

源文件为 `scripts/build_underworld.py`，由 `scripts/build_content.py` 导入，完整重建会保留扩展。`data/content_manifest.json` 给出当前统计；严格事件 Schema 为每一种效果分别规定必填字段与允许字段，拒绝未知操作、缺项和额外字段。

`node --test tests/narrative.test.js` 的 21 项叙事检查通过：全部 910 个结果实际执行、28 个结局条件、全事件候选、零现金退路、固定随机结果、完整人生，以及从真实立案到服刑、释放、求职的连续流程。合法案卷夹具通过 Core 创建和推进，不用随意伪造刑期字段。

完整 Core、存档和浏览器验收记录见 [v1.1 验收与发布](V1.1_验收与发布.md)。这些检查验证当前规则的一致性；长期难度、不同随机人生的内容密度与刑期节奏仍可继续通过试玩调整。
