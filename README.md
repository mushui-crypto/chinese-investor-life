# 中国式赌狗：一生的筹码

**出生没得选，这一把怎么下，你说了算。**

一个中文单机人生与投资模拟游戏。从出生到晚年，在成长、工作、人情与市场之间做选择：可以攒钱过日子，也可以押上家底；赚到的钱要付账，欠下的债和许下的承诺会留到以后。

## 玩法与特色

### 从一个家庭出发，走完自己的人生

12 种家庭背景影响开局。出生、童年、学生时代、大学或就业、婚恋与退休相互衔接；成长习惯、人物关系和过去的决定会影响后续事件。成年后以阶段选择、关键事件和阶段结算推进，也可以展开具体的一天，安排上课、工作、休息和看盘。

### 赚钱、交易，也要生活

现金、资产和债务分别记账。生活费、伙食、工资到账日、借款利息和还款日都会影响手里的钱。健康、疲劳与工作表现也有实际后果。资金归零后仍可以打工、求职、变现或寻求周转；能否重建生活，取决于剩下的条件与后续选择。

### 不同市场，有不同的玩法

| 市场与活动 | 主要体验 |
|---|---|
| A 股、港股、美股 | 虚构公司、地区交易单位、消息与持仓；A 股包含 T+1 限制 |
| 基金、债券 | 申购、持有、退出与资金安排 |
| 期权、期货、外汇 | 方向、期限、保证金与杠杆后果 |
| 加密现货与合约 | 离线历史行情、现货及逐仓杠杆交易、爆仓与退出 |
| 房产、天使投资、高收益项目 | 长期投入、锁定、回款、退出及后续事件 |
| 虚构赌局 | 龙虎斗、百家乐、斩龙、骰宝、单零轮盘、老虎机与红黑牌 |

市场根据年龄、资产、能力和剧情逐步开放。下单按实际现金、单位与费用结算；生活费提醒保留选择空间，后续开支和债务照常发生。

### 故事会记住你做过什么

网赌、Crypto 与高收益项目都有长期事件线：参与、获利、亏损、退出、重遇和亲友关系相互关联。婚恋家庭、工作变动、旧约及案件也会留下后续影响。结局和人生小记回看实际经历与账本，存档可导出后继续游玩。

界面采用生活场景插画、人物立绘与桌面多栏布局，并适配手机窄屏和减少动态效果的偏好。

## 快速开始

### 从源码运行网页游戏

安装 **Node.js 22 或更新版本**，然后执行：

```sh
git clone https://github.com/mushui-crypto/chinese-investor-life.git
cd chinese-investor-life
npm start
```

在浏览器中打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。私有仓库需要先获得访问权限。

网页游戏使用原生 JavaScript、CSS 与本地数据，运行前无需执行 `npm install`。也可以运行 `npm run launch` 自动打开浏览器，或使用项目根目录的 `启动游戏.bat` / `启动游戏.command`。请通过本地服务访问，直接用 `file://` 打开 `index.html` 无法正常加载模块和数据。

端口被占用时可设置 `PORT`，例如 macOS / Linux 下执行 `PORT=4174 npm start`。更换端口会改变网页存档所属的站点地址，迁移前请先导出存档。

### 关于存档

- 网页版提供 3 个本地存档槽，支持存档文件导出与导入，以及人生小记下载。
- 网页存档按浏览器和站点地址隔离；换电脑、换浏览器、清理网站数据或更换访问地址前，请主动导出备份。
- Windows 便携版优先将数据保存在程序旁的 `userdata/`；目录不可写时回退到系统应用数据目录。迁移便携版时请连同数据目录一起保留。
- 项目没有云端存档服务。运行时读取本地资源，不连接真实交易账户。

## 开发与校验

需要 **Node.js ≥22**；内容校验与内容生成另需 **Python 3**。

```sh
npm test                 # Node.js 自动化测试
npm run check:content    # 剧情、引用、条件与数据结构校验
npm run build            # 生成 dist/ 静态发布目录
```

本次仓库整理在 macOS 本机完成：**960 项自动测试通过**，内容校验 **19,453 项检查通过**，静态构建成功。这是本地校验记录；浏览器全量验收和 Windows 实机启动需要分别执行。

### 浏览器验收

先启动游戏服务，并准备 Playwright 与 Chrome。Playwright 不在当前锁文件中，需由开发环境另行提供；可通过 `PLAYWRIGHT_PATH` 指向模块路径。

```sh
npm run qa:browser       # 浏览器流程验收
npm run qa:all           # 全量 QA 调度
```

支持通过 `GAME_URL` 指向游戏地址，`QA_REPORT_DIR` 指定报告目录。完整可用命令见 [package.json](package.json)。浏览器脚本创建独立测试上下文，不使用玩家当前标签页的存档。

`qa:compat` 需要本地旧版发行 ZIP，支持 `COMPAT_ARCHIVE` 指定路径；部分历史发布脚本依赖旧报告及旧发行包，不能仅凭全新克隆运行。验收截图与历史备份不随仓库上传。

## 构建与发布

### 静态网页

```sh
npm run build
```

将 `dist/` 的内容放到静态服务器即可运行。构建会复制游戏源码、数据、文档与运行素材，过滤大部分原始 PNG，保留需要的图片。也可用以下方式在本机检查构建结果：

```sh
# macOS / Linux
SERVE_DIST=1 npm start
```

### Windows x64 便携版

安装桌面开发依赖后打包：

```sh
npm ci
npm run build:windows-portable
```

脚本依赖 Python 3 与 `unzip`，使用 Electron 和 Electron Packager 生成 Windows x64 应用及 ZIP，输出到 `releases/v1.63.0/`。安装依赖和首次打包需要下载相关包与运行时。同版本发布目录已有产物时，脚本会停止以避免覆盖。

打包后的程序解压后运行 `中国式赌狗.exe`，玩家无需另装 Node.js。当前仓库只托管源码与素材，历史 ZIP 和便携安装产物保留在本机；尚未上传 GitHub Release。跨平台打包成功与 Windows 实机可运行是两项独立检查。

## 项目结构

```text
.
├── index.html          # 网页入口
├── src/
│   ├── game/           # 游戏规则、叙事、市场、生活与存档
│   └── ui/             # 界面与交互
├── data/               # 剧情、家庭、人物、结局与离线行情
├── public/assets/      # 运行素材及原始美术资源
├── desktop/windows/    # Electron 桌面入口
├── scripts/            # 本地服务、生成、打包、校验与 QA
├── tests/              # Node.js 测试
├── docs/               # 创作、系统设计、数据来源与更新记录
├── reports/校验报告.md  # 当前内容校验摘要
├── PRODUCT.md          # 产品定位与设计约定（含历史记录）
└── DESIGN.md           # 视觉与交互设计说明（含历史记录）
```

`node_modules/`、`dist/`、`.build/`、`releases/`、`output/`、历史 ZIP、验收输出和本地配置由 `.gitignore` 排除，不会随源码提交。原始美术资源保留在仓库中，因此首次克隆的体积较大。

## 数据与内容维护

`data/events.json` 是展开后的事件数据。`scripts/build_content.py`、`scripts/build_underworld.py`、`scripts/build_relationships.py` 等脚本包含内容生成来源；事件效果由 `src/game/core.js`、`src/game/narrative.js` 及对应模块执行。

修改内容后，应同时检查生成脚本、输出数据、事件引用、存档兼容与实际结算，并运行内容校验和相关测试。生成脚本可能重写数据；请先确认目标脚本的覆盖范围。下载并重新生成离线加密行情可使用 `npm run data:crypto`，此步骤需要网络。

## 内容边界与许可

本作中的资金、交易、赌博和法律后果均为游戏系统。部分行情使用带来源的离线真实快照，其他市场价格、收益、手续费、收入与风险结算包含虚构或简化规则；不构成投资建议，也不提供真实交易或真实投注功能。

仓库尚未指定开源许可证。源码与素材上传到 GitHub 不代表授予开源使用、再分发或商业使用许可；如需使用，请先与项目所有者确认授权及相关数据来源的使用条件。
