# 中国式赌狗 v1.63.0

出生没得选，这一把怎么下，你说了算。一个从出生到晚年的人生与投资模拟游戏，包含成长选择、工作、关系、资产交易和风险后果。运行使用本地剧情及离线行情，不连接真实交易账户。

## 快速运行

需要 Node.js 22 或更新版本。在项目目录执行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。网页运行不需要先安装依赖；需要自动打开浏览器时可执行 `npm run launch`。请通过本地服务访问，不要直接双击 `index.html`。存档保存在当前浏览器中，迁移设备或访问地址前请在游戏内导出。

## 仓库结构

| 目录 | 内容 |
|---|---|
| `src/` | 界面、游戏规则、叙事与存档逻辑 |
| `data/` | 剧情、人物、市场与离线行情数据 |
| `public/` | 运行素材与原始美术资源 |
| `desktop/windows/` | Windows Electron 桌面入口 |
| `scripts/` | 本地服务、内容生成、校验、打包与浏览器验收 |
| `tests/` | Node.js 自动化测试 |
| `docs/` | 设计、系统规则、数据来源与历次更新说明 |

## 校验与构建

```sh
npm test
npm run check:content
npm run build
```

构建结果位于 `dist/`，可部署到静态服务器。Windows 桌面打包先执行 `npm ci`，再执行 `npm run build:windows-portable`，结果写入 `releases/`。桌面依赖仅用于开发和打包。

浏览器验收另需 Playwright 与 Chrome，可通过 `PLAYWRIGHT_PATH` 指定 Playwright 模块，并使用 `GAME_URL` 指定已启动的游戏服务。完整验收入口及存档兼容限制见文末「开发与发布」和「全量 QA」。旧版兼容验收及部分历史发布脚本依赖本地旧发行包或历史报告，这些文件不随仓库上传。

仓库保留源码、原始美术、数据、文档与测试；历史 ZIP、安装包、`node_modules/`、构建缓存、验收截图和源文件备份留在本机。尚未指定开源许可证，上传到 GitHub 不代表授予开源使用许可。

```sh
npm run qa:legal      # 案件、服刑、出狱与旧存档浏览器验收
npm run qa:experience # 市场解锁、人物与新界面浏览器验收
npm run qa:desks      # 全部交易界面、T+1、合约、历史行情、网赌与窄屏
npm run qa:behavior   # 盘外事件、还款日历、限额、家庭关系、提现与恢复
npm run qa:rescue     # 求生弹窗、六种借款及费用
node --test tests/health-survival.test.js  # 伙食、健康、就医、工资与旧档兼容
npm run qa:gambling   # 七种赌局、斩龙、千倍大奖、现金归零和窄屏
npm run qa:compat     # 从真实旧发行包生成旧档，COMPAT_ARCHIVE 可指定版本
npm run data:crypto   # 下载 Binance 公共历史归档，校验 SHA256 并生成快照
npm run build         # 生成 dist 静态发布目录
```

浏览器验收依赖 Playwright 与本机 Chrome，仅用于开发检查；游戏运行无第三方依赖。可通过 `PLAYWRIGHT_PATH` 指定 Playwright 模块路径。运行时只读取本地文件，不发送存档或连接交易账户。

发布目录通过任意静态服务器即可运行；不要直接用 `file://` 打开 index.html。存档按浏览器和站点地址隔离，换端口、换浏览器或换电脑前请导出。源目录包含测试与完整美术 PNG，发布包只保留游戏使用的压缩 WebP。

“所有可能性”通过基础事件、条件、分支与延迟回响组合扩展，不声称穷尽现实世界或无限人生序列。后续新增内容沿用现有编号与格式。
